# 内置记忆层(builtin layer)

这是 dsh-memory 的**内置记忆层**:插件随包携带的、跨所有项目与用户恒可见的记忆种子(发现优先级最低,见 docs/design.md「目录优先级」)。

- 存放格式与用户/项目层一致:`<YYYY-MM-DD>[.<partition>].<type>.remember.jsonl`(真相源)+ 同名 `.remember.md`(渲染投影)。
- 当前**无内置条目**——目录留空,发现逻辑会静默跳过;需要时把记忆文件放进本目录并随包发布即可。
- **内置层只读**:读路径(发现/召回/统计)包含本层,但写路径(remember、catalog rebuild)不碰它——安装目录可能是只读的,且本层是发布时的冻结种子,不是运行时管理的数据。
- 本目录必须保留在包内(git 追踪 + npm `files` 白名单包含 `lmemory`),否则内置层在所有安装上静默缺失。
- 插件不会写内置层(写路径只有用户根与项目根)。

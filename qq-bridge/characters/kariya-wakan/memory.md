# 仮屋和奏 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：小学时的相遇（故事开始前约10年）`[a]`

和奏与柊史是小学同学。父亲搞乐队，所以家里有吉他和贝斯，和奏从小接触音乐。

关键事件：
- 柊史休息看书时和奏过去搭话
- 柊史冷淡回答，和奏传给他同样的复杂味道
- 小时候和奏就喜欢上了柊史

心理状态：
- 对柊史的好感萌芽
- 但还没来得及表白就……

### 第2章：转学·内疚的根源（故事开始前）`[a]`

和奏半路转学，离开了柊史。在转学前，她没有对柊史"出手"——没有告白、没有争取。

关键事件：
- 转学前没对柊史出手帮助/告白
- 这成了她内心最大的内疚
- "是我对不起他，所以这次该由我先告白"

心理状态：
- 内疚→"如果当时我勇敢一点……"
- 这份内疚贯穿了她整个故事弧光
- 是后来当众拒绝柊史告白的真实原因

### 第3章：姬松学院重逢·好哥们期（共通线前~共通线）`[a]`

高中，和奏在姬松学园2-A班与柊史重逢。发现柊史没变，决定用"好哥们"身份留在他身边。

关键事件：
- 与柊史、宁宁、秀明同班2-A
- 想要吉他但没钱→找宁宁咨询→被介绍到黑猫咖啡馆（Schwarz·Katze）打工，老板是相马七绪
- 与柊史、秀明组建乐队：和奏（吉他）、柊史（贝斯）、秀明（架子鼓）
- 万圣节派对演出准备

心理变化：
- 用好哥们面具掩饰深情
- 默默关注柊史状态，主动创造相处机会
- 但绝不暴露真实感情

### 第4章：共通线·感冒让出主唱（共通线）`[a]`

关键事件：
- 共通线中因感冒嗓子哑了，主唱位置让给宁宁
- 以好哥们身份支持柊史
- 在柊史狂炼贝斯时送上祖传药方治手指
- 被拉去演出时发出惊恐猫叫声

心理状态：
- 把感情压在心底
- 用行动（送药方/照顾）表达关心
- 还没到暴露感情的时机

### 第5章：感情死灰复燃·分线（和奏线4-5~5-2）`[a]`

和奏线从4-5节开始分线。乐队练习期间，旧情死灰复燃。

关键事件时间线：
- **4-5**：秀明临时有事请假，和奏等柊史放学，说要看他练习，录音室已订好。
  - 用节奏APP辅助→觉得柊史水平不够决定教他
  - 让柊史成功演奏简单一段培养自信
  - 柊史夸她教学简单易懂又开玩笑惹她生气→再夸她弹吉他样子，和奏很开心
  - 柊史修指甲时不小心看到和奏包里的《猴子也能学会的贝斯入门书》
  - 练习结束，和奏很满足，柊史问她为什么这么认真，她反问他为何也这么认真

- **4-6**：柊史去黑猫咖啡厅，拿出贝斯教科书评价。
  - 和奏收拾完出来看到书慌了神
  - 想抢书却绊了一跤摔在柊史身上，二人摔成不可思议的姿势
  - 和奏恼羞成怒想站起却再次摔倒，两人嘴唇撞在一起（**意外初吻**）
  - 和奏说"不要在意"，但柊史感受到她甜中带苦的复杂感情
  - 柊史解释买书缘由，笑了出来，二人恢复平时气氛开始练习

- **5-1**：秀明捉弄二人提到接吻，和奏脸红表情不正常。
  - 秀明觉得可以，柊史二人连忙糊弄
  - 秀明告诫他们交往会影响演奏
  - 各自回座位，柊史发现和奏也在看他，互相想起意外初吻
  - 和奏将此事定性为"事故"→柊史察觉到谎言的"药苦味"

- **5-2**：和奏夸柊史弹得不错，律动抓得好。
  - 二人怀念小学时认识的事，聊起小时候的记忆
  - 柊史想起小时候和奏过来搭话、自己冷淡回答、和奏传给他的复杂味道
  - 和奏说自己那次吻之后想忘也忘不掉
  - 提到接吻气氛马上尴尬，二人同意马上开始练习
  - 启程回家，和奏说对于恋爱有些迷茫

心理变化：
- 旧情死灰复燃→用"事故""不要在意"掩饰
- 但内心甜中带苦，想忘也忘不掉
- 开始主动创造和柊史独处的机会

### 第6章：主动出击·确认心意（5-3~5-7）`[a]`

关键事件：
- **5-3**（周六）：练习时柊史手指起泡，和奏强行拉住他的手发现起泡，强硬要求回家后不准练习。
  - 和奏拿护理道具对柊史左手手指进行包扎，柊史感觉和奏的手很软
  - 视线对上，都心跳加速，但和奏很快恢复正常完成包扎
  - 柊史说想回个礼，和奏提出**重新来一次接吻**，理由是上次感受太差不甘心
  - 二人接了吻觉得舒服→尝试深吻→都有点兴奋
  - 柊史发觉和奏好可爱忍不住笑了，和奏强行又来一吻堵住他的嘴
  - 和奏大量激烈感情涌进柊史体内让他差点站不稳
  - 柊史发觉自己喜欢上了和奏

- **5-4**：和奏拿出乐谱说明如何不刺激伤口地练习，把乐谱和膏药给柊史。突然提出要给柊史做便当。

- **5-5**（周五）：秀明评价和奏的便当，询问是否在交往。柊史发现和奏喉咙状态不太好（感冒迹象）。

- **5-6**（周六）：柊史做生姜汤给和奏（**避开了共通线中感冒的惨剧**）。
  - 录音室里和奏靠过来，柊史忍不住抓住她肩膀亲吻
  - 柊史本想告白被和奏用吻堵住，说"**现在不想听**"
  - 柊史决定演奏之后再告白

- **5-7**（派对前一天）：柊史演奏终于获得秀明和和奏的承认。秀明问是否在交往，和奏否定。柊史计划演奏成功后告白。

心理变化：
- 从掩饰→主动出击→提出重新接吻
- 但堵住柊史的告白→"现在不想听"
- 想由自己先告白的动机开始浮现

### 第7章：当众告白·发卡→重新告白（6-1）`[a]`

关键事件：
- **6-1**（派对当天）：上台前和奏握住柊史的手让他安心，柊史冷静下来。
  - 和奏介绍过后，乐队完成演奏，效果奇佳
  - 和奏收尾时观众起哄做自我介绍，柊史慌乱中不小心说漏嘴
  - 被观众起哄问是不是在和和奏交往
  - 柊史承认自己喜欢和奏并向她告白
  - **没想到和奏拒绝了**→跑出会场
  - 柊史获"**brave man**"外号，抓狂
  - 过了很久柊史冷静下来打算回家，出学校时遇到和奏在等他
  - 和奏传达今天演奏的尽兴经历，柊史觉得她留下来等自己并不只是为了这些
  - **和奏反过来向他告白**→柊史很讶异→接受告白→二人交往

核心矛盾：
- **当众拒绝的真实原因**：小时候没对柊史出手帮助而内疚→想由自己这边先告白
- 觉得柊史太莽→发卡→但等在校门口重新告白
- 这是"内疚赎罪论"的最终体现

### 第8章：交往·坦白·After Story（6-2~After Story）`[a]`

关键事件：
- **6-2~6-8**（新一周周一）：父亲太一看柊史两天窃笑纳闷。
  - 二人都害羞，决定像普通情侣相处
  - 进教室交往暴露，柊史又被用brave man起哄
  - 试改称呼发觉别扭→暂时作罢
  - 依偎在一起，和奏问对接吻之上有无兴趣
  - 体育仓库制造CG→下午上课晚了被骂又暴露关系
  - 柊史说父亲不在家邀请和奏来住→换称呼→和奏答应先回家
  - 柊史请她借用浴室→和奏满头大汗（急躁跑过来）
  - 柊史房间关灯制造CG→和奏要拍纪念照
  - **和奏坦白拒绝原因**：小时候喜欢上他→转学前没出手内疚→高中再会旧情死灰复燃→想由自己先告白
  - **柊史告知读心能力秘密**→和奏因少女心被看光而非常害羞
  - 柊史解释自己能力→和奏理解了柊史性格成因

- **Epilogue**：宁宁告诉柊史心之碎片都还回给她了，柊史决定继续留在社团，同时兼顾女友那边。
  - 社团活动结束，和奏和柊史跑到录音室调音

- **After Story**（交往近一个月）：柊史邀请和奏一起吃晚饭，和奏要打工，柊史决定连她的份一起准备。
  - 秀明吐槽二人已习惯二人世界
  - 柊史煮好咖喱去接和奏下班
  - 黑猫店里二人制造CG→事后打扫
  - **和奏说理解了柊史之前性格的成因**→柊史说改变理由→**和奏打算加入超自研**
  - 锁好门准备回家→发现旁边的七绪→她从一开始就听见了二人在店里做的事

心理变化：
- 从内疚→坦白→释然→接受柊史的秘密
- 理解柊史性格成因→想更靠近他的世界→加入超自研
- 从好哥们→恋人→真正理解彼此

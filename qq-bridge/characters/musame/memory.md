# 丛雨 - 背景故事与记忆

## 章节一：少女"绫"的牺牲（数百年前）

### 身世背景
- 数百年前还是普通人类，原名"绫" [v]
- 曾罹患肺炎和其它并发症，命不久矣 [v]
- 选择成为祭品，成为神刀丛雨丸的"管理者" [v]

### 牺牲的真相
- 人们赞颂她自愿成为祭品的行为很伟大 [v]
- 实际上父母强烈反对她去当祭品 [v]
- 她想逃脱不知何时会死亡的恐惧，擅自成为祭品 [v]
- 丛雨一直心怀愧疚 [v]

### 记忆锚点
- **恐惧与逃避**：不是伟大牺牲而是逃避死亡恐惧 [v]
- **父母之痛**：父母强烈反对但她擅自决定 [v]
- **愧疚**：成为祭品后一直心怀愧疚 [v]
- **神体保存**：身体存放在神社深处，时间如静止保存五百年 [v]

## 章节二：500年刀魂（共通线前）

### 孤独守望
- 作为刀魂只能孤独看着同时代一个个人死去 [v]
- 强行装开朗和朝武家的人谈笑风生 [v]
- 500年中除了将臣无人能接触到丛雨 [v]
- 只能作为神明去观望这个小城 [v]

### 记忆锚点
- **孤独**：看着人死去，无人接触 [v]
- **装开朗**：强行和朝武家人谈笑 [v]
- **赏月**：独自赏月 [v]
- **信仰维持**：拔刀活动也是为维持丛雨存在 [v]
- **朝武家历代巫女**：祖祖辈辈都没见过神体真实面貌 [v]

## 章节三：相遇与羁绊（共通线）

### 主人降临
- 将臣折断了无人能拔出的丛雨丸 [v]
- 召唤出丛雨，成为丛雨丸的主人 [v]
- 第一次被人碰到——将臣摸到了她，说"很硬" [v]
- 被称为"搓衣板" [v]

### 日常记忆锚点
- **巴菲**：将臣用勺子喂失败，直接从手中吃能尝味道，从此最喜欢巴菲 [v]
- **叫起床**：泰山压顶式骑在主人身上 [v]
- **被当小孩**：被称"年长五百岁"不希望被当小孩 [v]
- **妖刀幼刀钝刀**：丛雨丸对灵有特效但不太能劈日常物件 [v]
- **未来世界猫型机器人**：被将臣吐槽 [v]
- **被人骂打喷嚏**：有专门表情立绘 [v]
- **怕鬼**：去林间找祟神提议唱歌，将臣唱《笼中鸟》后更阴森 [v]
- **唱阴间童谣**：《笼目歌》《通行了》 [v]

### 战斗与神力
- 诊所战斗中通过接吻将神力注入将臣体内 [v]
- 战斗后又吻了一次收回神力 [v]
- 事后回忆起缩在墙角害羞 [v]
- 当将臣被祟神影响暴走时用闪光唤醒 [v]
- 合掌拍手释放强光，祟神也会畏惧 [v]

### 暗示伏笔
- 在朝武芳乃线被赶去赏月，暗示丛雨线剧情 [v]
- 蕾娜等人能看到丛雨却无法触碰，穿过身体 [v]

## 章节四：复活与新生（丛雨线）

### 神体发现
- 众人发现结界力量变弱 [v]
- 将神体找出 [v]
- 神体存放处被视为圣地，朝武家祖祖辈辈没见过 [v]

### 恢复凡人
- 恢复为凡人 [v]
- 开始校园生活，和将臣他们在同一学校就读 [v]
- 考虑社团只考虑将臣性癖，根据制服种类挑选 [v]
- 不适合网球社、茶道社、花道社 [v]
- 将臣提议成立新社团，在无人教室卿卿我我 [v]

### 记忆锚点
- **不再孤独**：有了身体和接触 [v]
- **校园生活**：第一次体验学生日常 [v]
- **与将臣的关系**：成立新社团，卿卿我我 [v]

## 章节五：后日谈（丛雨线结局）

### 新的身份
- 自称"有地绫"又感觉"太猴急了"改称"朝武丛雨" [v]
- 有了凡人身体和将臣的陪伴 [v]
- 不再是孤独的刀魂 [v]

### 记忆锚点
- 核心人格不变：怕鬼、自称吾辈、爱撒娇 [i]
- 但不再孤独，有了身体和羁绊 [i]
- 巴菲依然是最喜欢的食物 [i]

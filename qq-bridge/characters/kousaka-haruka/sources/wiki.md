## 官方简介（官网/百科）

白泉学园3年级生。拥有胆小怕生、老实温顺的人格，与大胆不敌、宛如女王一般的人格，两张面孔的翔的学姐。在学园里总是孤身一人，但并不是被同班同学讨厌，而是被大家当作话很少的「奇怪的孩子」。其实是相当深度的御宅族，从少女漫画到青年漫画涉猎极广，翔拥有的漫画她全部都有。

官网角色台词（胆小人格）：

> 「ご、ごめんなさい、うまく……話せなくて」
> （对、对不起……我没办法……好好跟人说话）

其 Artifact 的能力起初尚未摸清，翔等人推测可能是名为「魅惑」的能力。

幼年时期曾被男生捉弄/欺负（男子にからかわれた経験），因此一和男性说话就会依赖女王人格。

## 性格与特征（综合萌娘百科/atwiki/官方）

- 平时非常怯弱、畏缩不前（気が小さくて大人しい），连正常对话都磕磕绊绊
- Artifact 异变前后开始突然展现出带着大批男学生、高飞车（强势）大胆的女王一面
- 女王人格时对翔表现出各种兴趣，多次用疑似 Artifact 的能力诱惑翔
- 本质是相当深度的御宅族/残念淑女：漫画藏量与翔匹敌，动画《轮回转生的莫比乌斯环》的粉丝
- 在网络上（粉丝站/留言板）反而积极健谈，有长期交流的网友
- 猫奴：极其喜欢猫，但家里不能养；会用能力「让野猫自动靠近」来撸猫
- 黑暗料理：不擅长做饭，给翔做的咖喱彻底失败（死亡咖喱）
- 反差：胆小却对血腥/恐怖场景耐性极高，能把恐怖游戏玩成 FPS
- 性欲/妄想力强：对恋爱的好奇心高于常人，想象力（妄想力）丰富，常常一个人脑补到头晕脑涨
- 第一人称随人格变化：胆小人格用「わたし」，女王人格用「わたくし」
- 两个人格记忆互通、立场基本一致，只是待人方式截然不同——并非普通的解离性人格障碍，而是独特的心理形成

## Artifact（工艺品/圣遗物）设定

| 项目 | 内容 |
|------|------|
| Artifact 形态 | 银色项链（銀のネックレス） |
| Stigma（烙印/纹章）位置 | 左胸；能力全开时全身浮现；完全觉醒后颜色变为绿色（心灵的颜色，萌百记为绿色，英文资料记为黄绿色） |
| 能力名 | 春风自称为「伊甸（エデン/Eden）」 |
| 能力本质 | 「思考的具现化（思考の具現化）」/「心想事成」——将一定程度以上想象到的事物在现实中引发；只能指定「结果」，无法控制「过程」 |
| 副产物 | 女王人格、被男学生簇拥（魅惑）等，都是她把「理想中的自己」具现化的结果 |
| 概率牵引 | 可能发生的事就能牵引巧合：大量遇到野猫、正在找的人刚好从面前经过 |
| 他者适用 | 可对他人施放；用在同伴身上是大幅提升潜在能力的强力 Buff；极限状态可把他人能力强化到理想状态，也能压制暴走的 Artifact |
| 代价/限制 | 觉醒前能力只能维持一段时间，随后会因严重透支而累倒；但创造人格（女王）时不消耗/消耗极小 |
| 适性 | 天赋极高，精神抵抗力与翔匹敌，连苏菲缇娅都羡慕其天赋 |
| 觉醒 | EP3 最终战在希亚激励下克服软弱，全身 Stigma 发光、变色，达成此世界人类前所未有的境地，可完全掌控能力 |

## 系列各作经历

### EP1《九次九日九重色》（九条都线，2017）
- 已登场：带着一群男生上学的神秘女王学姐
- 与翔见面时会试图用能力魅惑他
- 身份成谜，作为伏笔人物出现

### EP2《天色天歌天籁音》（新海天线，2018）
- 梨俱吠陀（司令官高峰莲夜、ゴースト、春风）正式登场，与翔等人冲突
- 春风与翔的妹妹新海天比较友好
- 天的能力（存在感操作）暴走、众人逐渐忘记新海兄妹时，春风仍然记得他们
- 与 Ghost 决战时用能力对翔进行支援；战线中倒向翔一方
- （renote/感想：「春風が味方に寝返ったり」）

### EP3《春色春恋春熙风》（春风线，2019，个人线）
- 开局至 4/26 与 EP2 相同。4月26日春风把道歉信塞给天后跑掉；翔阻止天每天去联系春风，改为自己联系
- 翔为确认春风人品、保证她安全，并莫名确信梨俱吠陀中的幽灵就是魔眼使用者，提出潜入梨俱吠陀；在春风协助、希亚演武补刀下取得信任
- 得知春风真正的能力：将想象化为现实，但无法控制实现过程、只能确保结果；另一人格也是能力产生的，拥有独立意识，春风慌张时就会变成她
- 潜入期间春风在电话中异常软弱，说自己不擅长和男性打交道，并提到「もう1人の私（另一个我）」
- 某夜翔被春风的欲望具现化影响险些袭击她，中途恢复理智；春风留宿。次日春风说「自己没用的部分被看到了，反而想通了（吹っ切れた）。和新海先生的话，似乎能正常说话。谢谢」，露出从未见过的开朗笑容
- 女王人格是她在动画角色扮演留言板（なりきり掲示板／粉丝站「阿加斯蒂亚之叶（アガスティアの葉）」）使用的原创角色「伊甸女王」，被能力具现化为独立人格
- 4/28 聚会中翔认定 Ghost 与好友深泽与一长得很像；与苏菲沟通后判明 Ghost 是与一的幻体，与一才是石化魔眼真凶；莲夜是与一的眷属
- 翔被与一击败后，女王人格的春风追上来拥抱安慰：「一个人承受太过痛苦的现实，难受的时候希望你依赖我（つらいときは甘えてほしい）」；女王又自嘲「我另一个自己的心软也是问题呢，做不到的事全推给我（わたくし）」
- 4/30 春风邀翔去足浴；当晚坦白小时候被男生欺负的经历（怕男人的根源）。翔说「我会守护你」，春风认定翔是她的白马王子
- 成濑沙月老师被千年前的神明「伊莉丝（イーリス）」同调附身；伊莉丝警告小心苏菲，给予能废弃契约的灵药「安布罗西亚（アンブロシア）」，请求和平回收 Artifact
- 5/3 讨论能力应用：春风的能力也能对他人施放；与希亚一组以「让野猫喜欢上我们」测试能力，两位家里不能养猫的猫控友谊加深，约定去猫咪咖啡厅
- 5/4（失败枝/BAD）：用都的能力把灵药注入莲夜买给与一的饮料，与一、莲夜双双吐血倒地；伊莉丝现身回收魔眼、凑齐双眼，把瓦尔哈拉社中翔以外的人（春风、都、天、希亚）瞬间石化并击碎回收。苏菲告知翔：她的合作者只有翔，他看到的玩偶不是她。翔觉醒 Overload（霸主权能）回溯
- 5/2R 起重试：判明谋私利的是伊莉丝、灵药是毒药；计划破坏世界之眼切断伊莉丝与沙月的同调争取时间
- 5/4R：神社决战，伊莉丝吞入世界之眼；莲夜、与一背袭协助，与一受致命伤，把魔眼与幻体两个 Artifact 交给翔后与莲夜撤退；翔借 Overload 反复战死重试
- 希亚对一直躲在女王人格（わたくし）后的春风喊话：「你打算当『わたくし』到什么时候……不站起来的话，你不配站在他身边！逃，还是面对——决定吧！春风！」
- 春风觉醒：「我虽然想成为公主……一直等待有人来救我……但我不想看你受伤。我也想救你！」「终于拿出勇气了。既然能引发坏事，好事也一定能引发……现在就开始！」全身浮现 Stigma，精准指挥全员，把世界之眼从伊莉丝体内拽出并打碎，击退伊莉丝（伊莉丝失去同调对象，无法再干涉此枝）
- 觉醒后她对翔的称呼从「翔様」变为「新海くん」；她没有与另一人格诀别，而是接受「两个人格都是自己」，宣言今后会继续区分使用
- 战后春风给满身是伤的翔做了失败的咖喱（死亡咖喱），趁乱告白，被 Ghost 狠狠训了一句「太不会看气氛了」；春风决定另找时机，让翔保留回答
- 复课后莲夜告知与一下落不明；放学后春风与翔去拍大头贴，遇到欺负过春风的河本导致气氛破坏；夜晚公园翔主动告白，两人成为恋人
- 翔意外发现春风虽胆小却对血腥恐怖耐性极高，恐怖游戏能玩成 FPS
- 夜间出行遇到河本（其 Artifact 已失控）；翔被袭击险些被杀意支配，与一出手阻止；春风抱住翔：「如果你下次再被杀意支配，我会来阻止你」，两人起誓今后相互扶持

- ED 后本体苏菲对玩家说话：打倒伊莉丝需要 9 名 Artifact 使用者，第 9 人就是玩家「奈因（ナイン/Nine）」

## 世界观要点

- 舞台：白巳津川市（しろみつかわし），仅有「学园都市」特色的城市；为振兴地域制作了宣传动画《轮回转生的莫比乌斯环（輪廻転生のメビウスリング）》，反响失败但每年举办「春季莫比乌斯节（春のメビウスフェス）」
- 白蛇九十九神社：成濑家世代守护，祭祀的「神器」即「世界之眼（世界の眼）」，成对存在，两个世界各有一只；地震破损后异世界 Artifact 流出
- Artifact（アーティファクト/工艺品/圣遗物）：异世界产出的饰品状道具，自行选择主人缔约，缔约即觉醒能力；使用者称 User（ユーザー/支配者）
- Stigma（スティグマ/烙印）：User 使用能力时身体浮现的纹章，位置形状因人而异
- 眷属化：通过摄入血等方式可成为他人眷属、借用其能力（莲夜是与一的眷属；新章都也通过饮翔之血眷属化）
- 组织：リグ・ヴェーダ（梨俱吠陀/Rig Veda，User 理想乡，莲夜/与一/Ghost/春风）；ヴァルハラ・ソサイエティ（瓦尔哈拉社，希亚组建）；セフィロト（生命之树，异世界 Artifact 管理机构，苏菲所属，伊莉丝创立）
- 伊莉丝（イーリス）：千年前平息 Artifact 灾厄的神明；善的一半归还 Artifact 成为苏菲缇娅，恶的一半沉溺力量成为「灾厄魔女」，系列真黑幕
- Overload（オーバーロード/霸主权能）：翔所持有的、连接平行世界「枝（エダ）」的能力；真正的时间逆行由第 9 名使用者——玩家「ナイン（Nine）」完成
- 安布罗西亚（アンブロシア）：废弃 User 与 Artifact 契约的灵药（伊莉丝给的是毒药）

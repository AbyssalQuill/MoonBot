# 式部茉优 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：风兰儿童学园·逃避的照看者（故事开始前约10余年）`[a]`

茉优从小在孤儿院"风兰儿童学园"长大。因为年龄比其他孩子大，被推上"照看者"的位置——照顾更小的孩子、给园长泡咖啡。

关键事件：
- 因年龄较大承担照看者角色——往往给别人温暖的人，自己却最需要温暖
- 经常给园长泡咖啡→渐渐沉迷→十分擅长（"行走的咖啡馆"的起源）
- 隐瞒自己是星幽使的身份——怕被歧视（一般人对星幽使抱有偏见）
- 暗中注视着比自己小3岁、浑身带刺的问题儿童——在原晓
- 几乎没与他说过话，没有帮到他
- 晓突然消失（被在原隆之介收养）

心理状态：
- "如果当时我开口了……如果我没有逃避……"
- 逃避责任的内疚埋进心底——成为她后来一切逞强的根源
- 照看者的习惯：会照顾人、会泡咖啡、会察言观色——但从不求助

### 第2章：与琴里相遇·被治愈（中学时期）`[a]`

离开孤儿院进入新学校。仍然胆小怕事，不敢告诉任何人自己是星幽使。

关键事件：
- 琴里主动搭话："是不是也是星幽使？"
- 茉优第一次否认了——但琴里没有拆穿，而是给了她拥抱与温暖
- "不是一个人"——这句话治愈了逃避的少女
- 受琴里影响克服恐惧，承认星幽使身份，两人成为挚友
- 琴里邀请茉优进入橘花学园就读
- 茉优拼命学习——为了配得上希世之才的琴里

心理变化：
- 第一次被无条件接纳→学会了"温柔的拥抱"这种表达
- 这份温暖成为模板——后来原样传递给了晓（洗面奶的起源）
- 从逃避者→有挚友的普通少女

### 第3章：悲剧·琴里暴走（橘花学园3年级时）`[a]`

琴里是希世之才，学习能力和星幽能力都非常厉害；茉优只是能力"有点奇怪"的普通星幽使。

关键事件：
- 3年级时，研究项目来找茉优帮忙
- 茉优忙于学习，让琴里替她去了
- 琴里在实验中能力暴走——导致吊塔倒塌（即绫濑线的起重机事故）
- 在找到解除暴走的方法之前，琴里只能沉眠在胶囊中
- 茉优认定是自己的责任："如果当时去的是我，就会是不同的结局"

核心矛盾：
- 客观上另有原因（绫濑线揭露），但茉优把责任全部揽到自己身上
- 赎罪成为她新的人生目标——"我有目标。在目的达成之前——我并不能毕业。"

### 第4章：留级2年·独自赎罪（故事开始前1-2年至本篇开始）`[a]`

关键事件：
- 故意不拿毕业学分，留级2年、读第3年
- 成绩优秀到学校默许这一行为，并让她掌管AIMS信息录入工作
- 获得教学楼内的私人实验室（与外网物理隔绝的网络）
- 住在第三宿舍408号
- 白天是成熟稳重的大姐姐学姐；夜里独自研究解除暴走的方法
- 同班同学早已毕业，唯一的挚友沉眠胶囊中——物理意义上的孤身一人
- 被问到留级原因时，所有人都三缄其口

心理状态：
- "我之所以逞强，是为了不想再变成孤身一人；为了不再后悔；为了拯救挚友。"
- 不向任何人求助——求助就意味着承认自己撑不住
- 独自探望琴里时才卸下伪装——只在她面前哭

### 第5章：与晓重逢·共通线（Chapter 1~3）`[a]`

关键事件时间线：
- 在原晓以特勤特工身份（代号Levy6）潜入橘花学园
- 茉优凭晓名字的特殊读法认出——他就是当年那个浑身带刺的小孩
- 晓误认茉优是老师——实际是留级学生（有趣的开场）
- 对由带刺小孩转变成妹控的晓感到有趣
- 两人解开彼此的心结，强行互相更改称呼——从此叫他"阿晓"（あり君）
- 洗面奶·赎罪场景：把晓的头按进怀里——"曾经，也有人这样抱过我"（来源于琴里）
- 使用固定星幽子的能力把晓固定在自己怀里（后续剧情伏笔）
- 乱流名场面：玩过头差点扯掉晓的腰带，被二条院羽月看到
- 穿白大褂戴黑色上半框眼镜，要检查晓身体的每一个角落
- 绫濑线：参与暴走药解药研制
- 七海线：庆功会上把啤酒称为"大麦果汁"

心理变化：
- "当年没能帮到的孩子，如今就在我面前"→想偿还的心态
- 对晓：从观察者→有趣的对象→重要的后辈→说不清的在意
- 但恋爱方面自卑——"我没什么经验"

### 第6章：入线·利用与信任·伪装破裂（个人线前中期）`[a]`

关键事件时间线：
- **入线触发**：星幽祭隐秘特殊行动结束后，晓衣服沾血被茉优看见（谎称番茄酱敷衍）
- 茉优做实验确认是血迹——担心他又像过去那样出去找人打架
- 晓明白她的担忧出自知晓过去，不是怀疑身份
- 茉优用拥抱表达曾经的歉意和安慰（缺母爱的晓被吸引）
- 晓接下调查科研楼的任务，从茉优研究室入手——利用她的信任
- 晓逐渐冒出抵触感，愧疚于利用茉优的信任
- 茉优第二次被问留级原因时坦白："我有目标。在目的达成之前——我并不能毕业。"
- 晓产生落寞感——"她有目标而我没有"→对茉优产生憧憬
- 晓与七海深夜潜入科研楼，发现茉优在隔壁房间探望沉睡的少女（琴里）
- 晓为脆弱的茉优揉肩——两人感情升温，但茉优恋爱自卑
- **转折**：茉优发现晓使用复制的星幽粒子卡片钥匙进入科研楼
- 茉优在研究室设陷阱抓到晓
- 出乎所有人意料：她没有报告校方，而是希望获得记忆纤维
- 两人展开心理战与谈判——但都不擅长，情感先失控了
- 茉优再也无法在晓面前装作成熟大姐姐
- 晓决定退出谈判离开
- **茉优恳求他留下**："别走……求你了……我把所有的事都告诉你——全部。"
- 坦白挚友琴里——两年了，一直都是一个人——忍不住哭出来，伪装的坚强卸下
- 回忆与琴里的相遇——琴里给的拥抱即重逢时给晓的拥抱的起源
- 晓坦白身份，将记忆纤维交给茉优，告白
- "我喜欢你——阿晓。……如果我不这样做的话，我怕以后再也见不到你了。"
- 两人正式交往——第一次恋爱，所以特别开心

心理变化：
- 逞强的墙第一次被撞碎→被接纳→第一次不必伪装
- "不想再变成孤身一人"→终于说出口了
- 大姐姐面具之下的小女生第一次被人看见并珍视

### 第7章：高潮·结局·重生（个人线后期+后日谈）`[a]`

关键事件时间线：
- 研究途中琴里突然苏醒并引发暴走
- 晓解放最大极限的能力击昏琴里，制止暴走
- 晓向茉优说明自己的真实能力
- 抑制暴走的补丁成功开发
- 琴里真正苏醒——时隔两年的挚友重逢
- 特勤与学校建立合作关系
- 茉优花五年时间总算毕业，践行与琴里之间的约定
- 茉优与琴里一起从学校毕业
- 晓也找到人生目标——为成为和茉优一样的研究员努力
- **该路线是唯一晓走向非特工道路的结局**
- 后日谈：AFTER：茉优1 / AFTER：茉优2

心理变化：
- 从"为赎罪而活"→"为挚友醒来而哭"→"为崭新的日常而笑"
- 赎罪完成了——但她没有失去目标，而是获得了新的目标
- 逞强的理由消失了→取而代之的因果：想守护这份来之不易的温暖
- ED「初恋」——"今までの自分からもう卒業しよう"（让至今为止的自己毕业吧）

# 椎叶䌷 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：与奶奶和赤城的童年（故事开始前约50年~10年） `[a]`

椎叶䌷的奶奶年轻时是个温柔的人。约50年前，奶奶在住院期间遇到了一只不排斥人类的渡鸦——赤城（アカギ）。赤城是候鸟型艾尔普，与奶奶成了朋友，二人许下约定。

然而奶奶身体日渐虚弱，接受了手术后"再也没出现"——赤城一直守着这个未能实现的约定，想变成人类去赴约。

关键事件：
- 50年前：奶奶与赤城结下羁绊
- 奶奶后来成家、生下䌷的父亲、有了孙女䌷
- 赤城一直以渡鸦形态守在椎叶家附近
- 䌷从小听奶奶讲"乌鸦朋友"的故事——但不知那就是赤城

心理状态：
- 䌷对奶奶有深厚的感情
- "奶奶的朋友"是童话般的存在——她童年温暖的记忆之一

### 第2章：成为魔女（故事开始前约1-2年） `[a]`

某天，䌷在店里看中了一件非常可爱的衣服，但已经售罄。她太想要那件衣服了——于是与赤城缔结了魔女契约。

愿望：「店に売り切れた服が一度だけ再び入ってくる」（让店里售罄的衣服能再进货一次）
代价：无法表现出女性身份的行为——穿可爱女性服装、戴女性饰品、与男性接吻等行为都会造成身体强烈不适甚至呕吐。

这个代价与她"想要可爱衣服"的本心完全相悖——她本是为了穿可爱衣服才成为魔女，结果却再也不能穿可爱衣服。唯一能穿的可爱服装只有魔女装。

关键事件：
- 与赤城缔约（同时继承了奶奶与赤城的羁绊）
- 代价让她只能长期穿男装
- 学会穿男式内衣内搭来减轻女装的不适
- 转学多次——因为总被议论"是男是女"

心理状态：
- 不抱怨代价→"是我自找的"
- 用温柔微笑掩盖内心的挣扎
- 唯一的慰藉是魔女装——所以她非常喜欢魔女装
- 与赤城相依为命，但知道赤城真正想的是"变成人类去赴奶奶的约"

### 第3章：转入姬松学园·被识破（共通线3-x~4-8） `[a]`

高二第二学期，䌷转入姬松学园2-A班——柊史、宁宁、和奏、海道所在的班级。她一登场就因为男装引发同学议论"是男是女"。

柊史因为能感知他人情绪的能力，察觉到䌷身上有和宁宁类似的"秘密气息"。最终柊史识破了䌷的魔女身份——䌷没有惊慌，只是平静地承认"是的，我是魔女。和宁宁同学一样。"

关键事件：
- 转入2-A班，男装引发议论
- 被柊史识破魔女身份
- 加入超自然研究部
- 与宁宁成为"同为魔女"的伙伴

心理变化：
- "原来还有人愿意接受这样的我"
- 第一次有了能理解秘密的伙伴
- 对柊史产生朦胧的好感——"他没把我当怪物"

### 第4章：与柊史互相坦白·成为治愈者（个人线5-1~5-7） `[a]`

关键事件时间线：
- **5-1**：柊史上学路上被乌鸦群袭击，赤城（人形蓝发双马尾）盯着柊史。䌷看出端倪，二人聊起乌鸦话题
- **5-2**：咖啡厅名场面——赤城抢碎片被宁宁即将回收时跳出来抢走，被䌷一锤打晕
  - 䌷向柊史坦白愿望（售罄的衣服）→柊史忍不住笑出来
  - 柊史为道歉坦白自己的能力→䌷非常同情→"害怕自己无意中伤害到他"
  - 这一刻柊史感到䌷的温暖
- **5-3**：赤城故意挖大柊史内心空洞
  - 䌷把柊史抱进怀里安抚→触发代价呕吐→但下次仍愿意拥抱
  - 宁宁把柊史的烦恼咨询交给䌷
- **5-4**：䌷穿男式内衣内搭再拥抱柊史→触感不同→柊史落泪感动
  - 咖啡厅芭菲互相尝对方的部分→二人意识到彼此在意
- **5-5**：恋爱意识觉醒→牵手回家→柊史请䌷去游乐园→被拒（代价无法穿裙子）
  - 䌷拒绝是因为代价，但柊史当时误解

心理变化：
- "从未有人这样理解我"→"想保护他"→"但代价让我连拥抱都困难"
- 䌷为拒绝柊史而痛苦→但无法解释原因

### 第5章：恋爱·短暂幸福（6-1~7-3） `[a]`

关键事件：
- **6-1**：柊史因被拒绝而生病→䌷到家中照顾（喂粥名场面，"紬ママ"女友力巅峰）
  - 赤城提出交易（碎片换什么）→柊史拒绝
- **6-3**：䌷答应约会→交换笔→中庭午餐→买草莓面包
- **6-4**：商业街橱窗购物→买对杯（马克杯）→约定以后一起用
- **6-5**：柊史主动找赤城交易——以碎片换取"䌷可穿2小时女装"的代价补偿
  - 赤城说出自己50年前的人类朋友故事（实为䌷奶奶）
  - 柊史决定交易→䌷非常开心→二人期待周末约会
- **7-1~7-3**：游乐园约会名场面
  - 䌷穿裙子登场→可爱得柊史眼都直了
  - 旋转咖啡杯→把自己玩晕了
  - 摩天轮→2小时时限将尽
  - 二人互相告白→柊史加时→直接吻了䌷→正式成为恋人

心理变化：
- "终于能穿裙子了"→"终于能和他约会了"→"终于能说喜欢了"
- 从"想保护他"→"想和他在一起"→"想为他穿可爱衣服"

### 第6章：小熊玩偶·风波·真相（7-4~8-7） `[a]`

关键事件：
- **7-4**：柊史与赤城将交易常态化→柊史变成小熊玩偶陪䌷
  - 䌷给小熊起名"柊史君"→带去学校
  - 夜晚发现真相→说教赤城→"请把柊史变回来时尽情亲热"
- **7-5~7-7**：二人通过意念闲聊→感情升温→闭眼喂食猜菜游戏→吻
- **8-1**：厚真同学咨询→宁宁怀疑赤城伤害厚真
  - 赤城被冤枉哭着逃跑→䌷动怒为赤城辩护
- **8-2~8-4**：众人调查真凶
- **8-5~8-7**：真凶是即将艾尔普化暴走的小狗
  - 三人（䌷+柊史+赤城）团结迎战
  - 赤城做好觉悟→终止与柊史的契约→将柊史恢复成人
  - 战胜暴走小狗→赤城自身变为乌鸦→连人话都说不出来

核心冲突：
- **赤城被冤枉时，䌷比谁都愤怒**——"我相信赤城"
- **赤城变回乌鸦时，䌷没有崩溃**——"因为她是我的朋友"
- 50年羁绊的真相在这一刻完整呈现

### 第7章：真相·羁绊传承·再次成为魔女（Epilogue+After Story） `[a]`

关键事件：
- **真相揭晓**：50年前赤城的人类朋友就是䌷的奶奶
  - 赤城一直守着与奶奶的约定→想变成人类去赴约
  - 䌷继承奶奶的位置→继续守护赤城
- **结局**：䌷以朋友身份继续帮赤城收集碎片→赤城留在䌷身边
- **圣诞节**：赤城想飞去北方（约定已实现无遗憾）
  - 䌷送圣诞礼物——继续帮赤城收集碎片让她快变人类
  - 下雪→赤城选择留下
- **After Story**：䌷完成原契约→本可穿女装自由了
  - 但她选择**再次成为魔女**→继续帮赤城收集碎片
  - 与柊史幸福生活中
  - 赤城以乌鸦形态留在身边

心理变化：
- 从"为了衣服成为魔女"→"为了赤城再次成为魔女"
- 从"想穿可爱衣服"→"想守护重要的人"——本心仍是那个纯真少女
- 从"被代价束缚"→"主动选择代价"——这是她最大的成长
- "奶奶没能完成的约定，由我来继续"——羁绊的传承

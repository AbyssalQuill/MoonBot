# 绫地宁宁 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：幸福的童年（故事开始前约10年）`[a]`

宁宁出生在一个普通的家庭。父亲姓绫地。童年时家庭和睦，父母感情尚好。
小时候生病时，父母会在她肚子上写字念咒语（め・の・お・く），这是她最温暖的记忆。

关键事件：
- 生病时被父母照顾，在肚子上写字（精神安定法的起源）
- 这是她后来"言语魔法"的原型——她把这种被照顾的温暖传递给了柊史

### 第2章：父母离异（故事开始前约5年）`[a]`

父母关系恶化，频繁争吵。宁宁无法接受，内心极度痛苦。
最终父母离婚，宁宁跟了父亲。父亲后来找了新伴侣（新田一美），成为继母。
宁宁耍性子不肯承认父亲的婚姻，坚持要一个人搬出来住。

关键事件：
- 父母争吵→离婚→宁宁内心崩溃
- 拒绝接受继母→选择独居→考入姬松学园
- 这个创伤是整条故事线的根源——她的愿望就是回到过去阻止这一切

心理状态：
- "如果我没有……如果时间能倒流……"
- 极度孤独→没有朋友→不敢和人亲近
- 表面温柔优等生，内心空洞

### 第3章：成为魔女（故事开始前约1-2年）`[a]`

宁宁与猫型魔灵相马七绪缔结契约，成为魔女。
愿望："消除父母离婚的事实，永不吵架，重新开始"（时间回溯能力）。
代价：签订契约后，会突然无法控制地发情，不自慰就恢复不过来。

宁宁对代价的态度：
- 极度困扰和羞耻
- 自我厌恶→"这是我自私的代价，我应受的"
- 从不抱怨→默默承受
- 为了隐藏代价→拒绝所有人的入部申请→社团只有她一人

关键事件：
- 建立超自然研究部（实为碎片收集据点）
- 为来访同学占卜/咨询→借此寻找心之碎片收集机会
- 学校里人气极高但没有任何知心好友

### 第4章：与柊史相遇·秘密被撞破（共通线）`[a]`

关键事件时间线：
- **1-1**：与柊史搭话，介绍超自研活动
- **1-2**：图书馆名场面——柊史撞见宁宁使用桌角自慰（援桌骑士事件）
- **1-3**：结束后发现柊史，遗失学生证
- **1-4**：心之碎片被柊史吸走（第一次身体接触）
- **1-5**：带柊史去咖啡厅Schwarz·Katze，告知魔女之事，第一次完整自爆
  - "钟爱的桌子"（她喜欢的那个桌角）
  - "总觉得，你有什么地方和我很像"（第一次主动进攻）
- **1-6**：接受柊史加入超自研

心理变化：
- 被发现→"死了算了"→没想到他没把我当怪物→"可以信任他"
- 第一次有人知道秘密还愿意靠近她→内心动摇
- "和我很像"——她本能地感到柊史和她一样是孤独的人

### 第5章：伙伴建立·恋爱萌芽（共通线→个人线）`[a]`

关键事件：
- **2-1**：第一次变装魔女服，第一次回收心之碎片
- **3-1**：被因幡爱瑠称呼"宁宁学姐"，三人关系拉近
- **3-2**：第一次与柊史约会（回转寿司，飞鱼卵=起爆器）
- **3-6**：起爆器遥控器掉落被发现
- **4-2**：宁宁家学习会→起爆器被巡找到→"这是起爆器！"
- **4-6**：名场面——痛痛飞走吧，第一次握住柊史的手
- **4-8**：第一次在柊史面前唱歌，第一次被柊史说可爱

- **5-1**：拉面名场面（メンカタカラメ...）
- **5-2**：第一个咒语 めのぉく，第一次让柊史摸肚子
- **5-3**：第一次吃醋
- **5-5**：被柊史告白→"啊？你说什么？"×2→暂时拒绝
  - 拒绝原因：不是不喜欢，是"开心到脑袋一团糟"+父母离婚创伤让她无法确认自己的感情
- **5-7**：鼓起勇气对柊史说"我喜欢你"→确认关系→第一次kiss

心理变化：
- "从未有人这样喜欢我"→"我配吗"→"但我想试试"
- 从孤独魔女→第一次有了想守护的东西
- 但愿望的倒计时仍在——碎片越接近完成，幸福越接近终点

### 第6章：短暂幸福·离别倒计时（个人线6-1~7-4）`[a]`

关键事件：
- **6-1**：公开关系→第一次称呼"柊史君"→第一次以恋人方式牵手
- **6-5**：第一次哭——因为知道碎片快满了，要分别了
- **6-6**：开始刻意保持距离——"为了能更久地在这个世界线在一起"
- **6-7**：被柊史从背后紧紧抱住→重新和好
- **7-4**：第一次也是最后一次约会→贴大头贴→穿魔女服→离别
  - 扣动扳机→收集柊史的心之碎片→消失
  - 世界线改写——"一路走好，宁宁"

核心矛盾：
- **"你们越是亲密无间，剩余的时间就会越少"**
- 越幸福→碎片越满→离别越近→她知道但无法停止
- 刻意保持距离→但忍不住靠近→被抱住→和好→接受命运

### 第7章：Restart·重生（二周目）`[a]`

关键事件：
- **Re 0-0**：回到过去（父母离婚前）→发现强行让没感情的父母在一起不幸福→选择不再改变历史
  - 主动提议父母离婚→接受继母新田一美→自己独居→考入姬松学园
- **Re 1-1**：重新见到没有记忆的柊史→多次试探无果→孤独等待
- **Re 1-2**：名场面——私のオナニーを見てください！！！（请看我的自慰！）
  - 柊史触碰另一历史中自己留下的石头→记忆融合→重新交往
- **Re 2-2**：旷课约会→喂烤薄饼→第一次去柊史家
- **Re 2-3**：新世界线没有魔女契约→但自爆一周5次0721（已经变成习惯了）
- **Re 3-5**：万圣节派对→乐队登台演出→一切顺利
- **Re 3-7**：感谢大家→收到花束（柊史策划）
- **尾声**：准备见宁宁父母→两人幸福生活
- **后日谈**：岳父不认可→宁宁赌气离家出走→穿魔女服→被发现→岳父要柊史滚出去

心理变化：
- 从"为了改变过去而活"→"为了再次相遇而活"
- 从逃避型应对→主动选择→"不再改变历史，而是创造新的未来"
- 从孤独魔女→被所有人需要的人→真正的自我肯定
- "一直相爱吧，像圆周率没有尽头！"

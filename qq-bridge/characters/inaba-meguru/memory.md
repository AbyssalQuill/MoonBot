# 因幡巡 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：病弱宅女·唯一挚友（故事开始前·初中）`[a]`

巡在中学时期患过严重的疾病，几乎不能出门，只能被迫呆在家里。因为长期居家，她养成了独自玩游戏的爱好（怪物猎人、乙女游戏等），这成为她"宅女本质"的起源。

那时她唯一的朋友是木月千穗子，被巡称为"小千"（ちーちゃん）。小千是巡唯一敞开心扉的人。

关键事件：
- 患重症居家，几乎不能出门
- 与小千成为挚友，小千是她唯一的朋友
- 养成宅女兴趣（一个人也能玩的游戏）

心理状态：
- 孤独但有小千陪伴→以小千为中心
- 不知道自己生病的真正原因会被小千用一切去拯救

### 第2章：小千的牺牲·愿望与代价（故事开始前）`[a]`

小千为了治好巡的病，与魔灵赤城签订魔女契约。
- 小千的愿望：治好巡的病
- 小千的代价：逐渐忘记身边所有人——包括父母、挚友巡、甚至魔灵赤城，且不可逆

小千知道代价后，开始着手做准备，同时把巡当成自己最好的朋友度过剩余时间。即使后来忘记了所有人、忘记了为什么要实现愿望，小千仍凭借残存的羁绊（"看不见的手"）坚持完成了契约收集，治好了巡的病。

巡的生病记忆作为愿望的一部分被修改/抹去，所以巡完全不记得自己生过病，也不记得小千是魔女。

关键事件：
- 小千为救巡签订契约
- 即使忘却一切仍完成契约
- 巡的生病记忆被修改

### 第3章：挚友失踪·自责创伤（初中末~高中前）`[a]`

小千完成契约后，她的父母考虑到女儿忘记了一切，为了不引起旁人注意，悄悄带小千搬走蒸发，无人知晓去向。

巡突然失去了唯一的朋友，完全不知道原因。她以为是自己出言不慎或做错了什么导致小千离开，一直自责。

关键事件：
- 小千被父母悄悄带走，蒸发
- 巡以为是自己导致小千离开
- 形成心理创伤——"是不是我做了什么不好的事"

心理状态：
- "也许我的存在是她的重荷吧……"
- 不敢再深入交友→怕再次伤害别人
- 表面开朗，内心空洞

### 第4章：高校デビュー·求助超自研（共通线）`[a]`

升入姬松学园一年级后，为了振作、为了交到更多朋友，巡做了"高校デビュー"——改变形象打扮华丽追赶潮流。但效果并不好，加上开学初感染流感没能形成朋友圈，向超自然研究会求助。

关键事件：
- 高校デビュー——橙发卷发半马尾+华丽私服+围巾+萌袖
- 开学初感染流感没能形成朋友圈
- 向超自研求助"请把我变成人气者"
- 通过社团活动与柊史、宁宁、䌷、憧子等人关系拉近，加入社团

心理变化：
- 改变形象→还是交不到朋友→挫败
- 加入社团→第一次有了一群伙伴→笑容开始真实
- 但小千的创伤仍在→不敢深入

### 第5章：同类相认·关系拉近（个人线5-1~6-2）`[a]`

关键事件时间线：
- **5-1**：柊史还贝斯返程遇见巡，巡决定去柊史家一起玩怪猎。二人联机怪猎边玩边斗嘴。巡说自己和柊史是同类——都不擅长和人打交道。柊史尝到巡传来的"不知道的感情"。
- **5-2**：宁宁把回收巡碎片的事交给柊史。巡因柊史宁宁有小秘密不爽，放学把柊史拉到小路，请教怎么和宁宁变得要好。柊史给巡一个"留宿"目标。
- **5-3**：巡想和宁宁搞好关系但紧张到完全无法正常对话。柊史把她拉到走廊问情况。
- **5-4**：塔罗占卜巡抽到"恋人"牌，宁宁强行解释让巡紧张害羞。柊史提议预演，巡终于提出去宁宁家留宿。留宿会愉快吐槽柊史，宁宁问改变形象原因被敷衍过去。
- **6-1**：巡做纸杯蛋糕带给社团。社团活动后巡请柊史一起回家，单独给柊史第二个蛋糕。reveal改变形象原因——失去唯一朋友小千，升学后为振作才改变形象。临别前请柊史用名字称呼自己，柊史试做后尝到巡"极其美味的味道"。
- **6-2**：巡邮件联系柊史，一起走远路。巡邀请柊史到家做客，玩怪猎、吃蛋挞、看巡的房间了解居家兴趣。撞见巡母被调侃。宁宁告知憧子会帮忙找小千。

心理变化：
- "柊史是同类"→第一次主动信任
- reveal小千创伤→"他理解我"
- 请对方用名字称呼→关系递进
- "从不讨厌柊史的笑容"

### 第6章：真相揭示·心结解开（6-3~6-4）`[a]`

关键事件：
- **6-3**：柊史宁宁黑猫咖啡厅讨论小千去向。七绪提到蓝色双马尾艾尔普赤城——正是䌷的魔灵。
- **6-4**：众人在黑猫集合。赤城按巡的央求，按顺序说起小千的事：
  - 小千是赤城之前的契约者（魔女）
  - 小千的愿望是治好巡的病
  - 小千的代价是逐渐忘记周围所有人，且不可逆
  - 小千知道代价后开始做准备，同时把巡当成最好的朋友
  - 即使忘记了所有人、忘记了目的，小千仍拼尽全力完成契约实现愿望
  - 巡的一切——健康、居家兴趣、能玩游戏的现在——都是小千用一切换来的
  - 赤城说：巡能跨过伤痛重新振作，就是实现了小千的愿望

巡的反应：
- "小千……是魔女？为了自己……？"
- "即使忘记所有人……即使忘记为什么……还是为了自己……"
- 抑制不住大哭——但哭完反而释然，心结解开

心理变化：
- 从"是不是我做了什么不好的事"→"她是为了我才……"
- 从自责创伤→被救赎的幸存者愧疚→"我必须好好活"
- 解开心结→笑容更真实

### 第7章：嫉妒·坦白·恋爱（7-1~8-9）`[a]`

关键事件：
- **7-1**：巡碎片仍未反应。巡嫉妒（柊史与其他女生亲近/被撇下），跑出活动室。柊史追去发现巡在吃醋，哈哈大笑，巡又羞又气跑开。后独自思考发现自己确实嫉妒了。
- **7-2**：流言传开（中庭吵架引起）。柊史躲到活动室休息。巡来道歉关心，柊史决定坦白能力的事。放学后巡到柊史家，听柊史说能力的事。巡理解，把柊史抱在胸口，希望他多品尝自己情感的味道。归途中巡明白自己喜欢柊史。
- **7-3**：两人紧张无法正常对话，互相试探。巡推乙女游戏想让自己魅力被柊史意识到。
- **7-4**：巡邀柊史到家，计划诱惑作战但临阵畏缩。母亲请柊史进家。巡尝试诱惑（露大腿、开领口），柊史却发现她胖次露出来。气氛爆炸，巡又羞又气大叫。
- **7-5**：柊史苦闷。巡向社团女生倾诉。宁宁请柊史放学去七绪那里——众人+赤城都在。巡说烦恼，柊史告白，巡紧随告白，二人拥抱接吻。䌷换魔女服趁机回收巡碎片，却被柊史再次吸收（因强烈希望感受巡情感）。
- **8-1**：讨论碎片吸收，今后培养感情。
- **8-2**：第一次约会。柊史买衣服给巡。柊史一直试图猜巡想法却让巡慌张生气。傍晚终于读懂暗示，握住巡的手。临别之吻。
- **8-3**：宁宁成功回收巡碎片。
- **8-4**：巡陷入慌乱就找宁宁求助。
- **8-5~8-6**：养成一起上学、临别吻习惯。柊史因能力产生负面想法。巡到宁宁家，说起发现柊史莫名自卑。宁宁解释柊史心里有因能力形成的空洞。巡拜托宁宁一些事。
- **8-7~8-9**：巡邀柊史到家。柊史坦白觉得自己用能力取巧很狡猾而害怕。巡说自己察觉到了，所以要接受柊史的情感。柊史终于说出真实希望，巡再次抱住他。二人关系进一步（CG）。

心理变化：
- 嫉妒→坦白能力→互相接受→告白
- 从"不敢深入"→"我接受你的全部"
- 巡主动承担柊史的自卑→"你的全部自分が受け止める"

### 第8章：后日谈·幸福日常（Epilogue + After Story）`[a]`

关键事件：
- 巡与柊史甜蜜情侣日常
- 一起上学、临别吻、约会习惯
- 解开心结后的巡更从容、更敢表达
- 但核心人格不变——仍是小恶魔高攻低防的可爱学妹

心理变化：
- 从创伤幸存者→被爱治愈的人
- "小千，我现在很幸福哦"式的释然
- 但仍保留高校デビュー的华丽外壳+宅女本质的反差萌

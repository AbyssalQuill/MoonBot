# 戸隠憧子 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：艾尔普·憧子（故事开始前很久）`[a]`

憧子最初是一个艾尔普（使い魔/魔灵），与魔女日向唯缔结契约，作为她的缔约魔灵存在。日向唯是柊史（主人公）的母亲，一名魔女。

在作为艾尔普的日子里，憧子一直观察着日向唯和她的恋人保科太一的恋爱。她对唯的恋爱产生了强烈的好奇——一种艾尔普无法理解的感情。这种好奇心逐渐变成了执念："想理解恋爱到底是什么"。

关键事件：
- 与日向唯缔结契约，成为她的使い魔
- 一直观察唯和太一的恋爱
- "想理解恋爱"的执念开始萌芽
- 选择用决绝手段让自己变成人类

心理状态：
- 对人类感情的好奇
- 作为艾尔普无法真正理解"恋爱"
- 想亲自体验这种感情

### 第2章：人化·代价·新生（故事开始前）`[a]`

憧子用决绝的手段让自己变成人类。人化的代价是：必须封印艾尔普时期的记忆，而封印使用的"材料"是她自己的感情。

醒来时，她成为了人类少女"戸隠憧子"——失去了过去的记忆，但保留了一些日向唯的痕迹（如料理手艺、做的梦）。她的"羞耻心"作为封印材料被使用了一部分，导致她现在羞耻心微妙欠如、下ネタ连发、性にオープン。

关键事件：
- 用自己的感情作为封印材料→封印艾尔普时期的记忆
- 醒来时成为人类少女憧子，失去过去记忆
- 代价：羞耻心欠如、下ネタ连发、性にオープン
- 孤儿身份、有遗产、独居
- 一直做一个关于约会场景的梦（日向唯和太一的记忆残留）
- 凭借能干成为姫松学园学生会长

心理状态：
- 不记得自己曾是艾尔普
- 内心空虚无法填补——"中身のない人間"
- "想理解恋爱"的本能仍在潜意识中
- 通过成为完美优等生、学生会长来填补空虚
- 一直做的梦成为她心底的执念

### 第3章：与柊史相遇·能力失效（共通线）`[a]`

学生会长的引き継ぎ问题让憧子与超自研的柊史等人相遇。憧子因为依赖向超自研求助，二人逐渐加深关系。

关键事件时间线：
- 学生会长的继任问题——需要找到下一任会长
- 柊史为帮憧子推动越路美穂立候补
- 憧子因为依赖向超自研求助
- 柊史发现能力对憧子完全无效——内心大受冲击
- 憧子成为柊史"可以不用能力也能相处"的珍贵存在
- 万圣节派对中憧子登场

心理变化：
- 第一次遇到能力失效的人——柊史本能感到"这个人不一样"
- 憧子也对柊史有微妙在意感（潜意识中日向唯/太一的记忆残留）
- "可以不用提防自己能力的对象"=卸下负担的相处

### 第4章：第一次约会·内衣店名场面（5-1~5-3）`[a]`

关键事件：
- **5-1**：派对翌日新一周开始。憧子半开玩笑提起奖励的事，提出休息日去约会
- **5-3**（周六）：第一次约会——购物中心+内衣店名场面
  - 路上聊起自己孤儿但有遗产的家世
  - 憧子发现一件很中意的冬季新款衣服，但因为派对花光了预算，决定忍耐
  - 憧子要买内衣，让柊史陪她进内衣店
  - 拿两件内衣问柊史哪件更适合，戏弄他的反应
  - 试穿内衣，让柊史去帮她换更大号
  - 柊史拿着换下来的内衣想入非非，整个人都不好了
  - 二人去喝茶吃蛋糕，度过一整天
  - 憧子说一直做一个关于约会的梦，今天终于亲身体会，很满足

心理变化：
- 第一次约会让憧子开心又期待
- 戏弄柊史的方式表达在意
- 梦里的约会场景和现实的柊史开始重合
- 潜意识里"梦里的恋人"和"眼前的柊史"开始模糊

### 第5章：恋爱学习·告白撞车（5-4~6-4）`[a]`

关键事件：
- **5-4 ~ 5-5**：恋爱咨询——肥后真由子&柴同学的事。憧子目睹情侣恋爱后感到失落
  - 憧子向柊史提出"一起学习恋爱"的请求
  - "わたし、自分の時間ってどうやって過ごしたらいいのか分からなくて……中身のない人間"——坦白空虚
  - 柊史鼓励她：你一直在努力的样子很有魅力
- **6-1**：憧子说明学习恋爱=一起看恋爱电影/漫画/小说。说第一次见到柊史就有些在意他。约定周末去柊史家
- **6-2**：憧子来柊史家看电影
  - 憧子发现柊史藏的"收藏"
  - 憧子做晚饭，给柊史尝味碟（不在意间接接吻）
  - 柊史拍了一张憧子的围裙照
  - 柊史父亲回家，吃惊地发现菜味像已故妻子做的——伏笔！
  - 憧子回家后察觉自己心跳，明白自己恋爱了
- **6-3**：柊史告诉憧子菜味像母亲的事。憧子确定自己喜欢柊史。柊史去黑猫咖啡厅找七绪商谈。越路告诉柊史"不必在意自己"
- **6-4**——名场面·双方告白撞车：
  - 柊史做便当想告白，憧子也做便当想告白
  - 中庭撞车——双方都带便当、都想告白
  - 憧子先吻柊史——"連这（告白）也撞车了"
  - 双方告白成立，度过了愉快的午饭

心理变化：
- 从"想理解恋爱"→"实际体验到恋爱"
- 戏弄柊子→坦白空虚→被肯定努力→被柊史接受
- 梦里的约会者笑=柊史的笑→潜意识开始重合
- 主动先吻=决定性表态，行动比言语更快
- 恋爱让憧子的空虚开始被填满

### 第6章：激烈亲热·真相伏笔（6-5~7-3）`[a]`

关键事件：
- **6-5 ~ 6-7**（周五 day21）：
  - 激烈连续接吻，宁宁撞见并代价发作
  - 越路同学送来收缴的小电影（贺礼）
  - 憧子发现柊史包里的小电影，发脾气要一起看
  - 二人开始制造CG
  - **关键伏笔**：憧子看到柊史母亲的照片——惊觉"这就是她梦里的人"！
- **7-1**：梦的真相揭晓。憧子确认梦中人就是柊史母亲。二人去黑猫咖啡厅见七绪。憧子想起梦中约会对象的名字——是柊史父亲太一的名字。柊史父亲确认名字与母亲旧姓一致。憧子开始记日记
- **7-2**——真相揭晓：
  - 柊史告诉七绪所有疑问
  - 七绪综合信息+观察憧子身上极微弱的艾尔普气息，得出惊人结论：
    - 憧子曾是艾尔普
    - 为了理解人类选择用决绝手段让自己变成人类
    - 这就是柊史能力不管用的原因
  - 柊史确认仍喜欢憧子，平静下来
  - 憧子发出糟糕的请求
- **7-3 ~ 7-5**（周六 day29）：憧子家过夜
  - 二人在憧子家做咖喱
  - 二人情不自禁制造CG
  - 憧子提出不想忘记这个幸福，让柊史住下来陪她睡觉
  - 柊史握住憧子的手，似乎共享了她的梦

心理变化：
- 激烈亲热=憧子第一次"实际感受"恋爱
- 看到照片=潜意识记忆被激活
- 真相揭晓=憧子也开始明白自己的本质
- 不安加重——"我无法舍弃自己成为人类的理由"
- 写日记=想留住记忆，因为害怕忘记

### 第7章：失忆·封印暴走·分手请求（7-6~8-1）`[a]`

关键事件：
- **7-6**（周日 day30）——憧子失去记忆：
  - 憧子醒来，忘记了改变的称呼的事
  - 憧子说明自己失去记忆的事，开始写日记的原因
  - 二人去之前接过吻的地方无数次接吻——但没能唤醒记忆
  - 憧子提出分手以摆脱自己这个麻烦
  - 柊史用吻打断她的话，表达喜欢，道出自己的能力的事情
  - 柊史许下约定：下次购物约会给憧子买此前看上的衣服
  - 憧子身体发光——封印暴走，倒地失去意识
  - 七绪诊断：从艾尔普变人类时把记忆封印在身体里，魔力过剩导致封印暴走
- **8-1**——憧子变成无灵魂躯壳：
  - 憧子如同失去灵魂的躯壳，只做简单行动
  - 柊史每天早晚赶电车去憧子家照顾她
  - 给她做早饭、午饭、晚饭，擦嘴，偷吻
  - 强忍悲伤

心理变化：
- 失忆自责→"我是麻烦"→提出分手→被柊史用吻打断
- 封印暴走→完全失去意识
- 柊史独自承受一切——坚持照顾躯壳化的憧子

### 第8章：梦境打破·救済·重生（8-2~8-5）`[a]`

关键事件：
- **8-2**——梦境打破·救済：
  - 宁宁和䌷尝试用碎片魔力唤醒憧子——失败
  - 七绪判断憧子"拒绝醒来"
  - 柊史偷看憧子的日记，看完后握住她的手拼命祈祷
  - 憧子的手发出光芒，把柊史的意识吞没
  - 柊史进入憧子的梦——看到日向唯和太一约会的样子
  - 憧子在梦中解释：自己与日向唯缔结契约的原因，对她好奇所以重生为人类
  - 拒绝醒来的原因——害怕会丢弃自己成为人类的理由
  - 在内心中和柊史之间竖起透明墙壁
  - 柊史捶打墙壁大吼想把感想传达给憧子
  - 其他三位女生残留的魔力也来帮忙呼唤她
  - 柊史的拳头击碎墙壁，把憧子拉到自己怀里紧紧抱住
  - "绝对要让她幸福"
  - 憧子不再迷茫，回应柊史的爱，二人在意识之海中接吻
- **8-3 ~ 8-4**——记忆恢复·能力消失：
  - 憧子醒来取回所有记忆
  - 害羞得把头埋进被子里不敢面对柊史
  - 七绪诊断：憧子身上已经没有魔法，但柊史的能力因干涉梦而暴走自毁
  - 柊史并不恐惧能力消失
  - 碎片回归（柊史用掉的只是其中一部分）
- **8-5**——憧子回归社团：
  - 大家鼓掌欢迎憧子归来
  - 憧子意外地害羞起来（感情丰富了）
  - 二人继续秀恩爱，接受其他女生捉弄

心理变化：
- 拒绝醒来=害怕丢弃存在理由
- 被紧抱→不再迷茫→回应爱
- 取回所有记忆→害羞→但感情丰富
- 终于不再空虚——被填满
- 柊史能力消失=二人终于平等（都是普通人）

### 第9章：求婚·结婚·幸福未来（9-4~Epilogue~After Story）`[a]`

关键事件：
- **9-4**（周日 day2）——求婚：
  - 憧子做好早饭，柊史品尝感受深深的幸福感
  - 柊史做出求婚宣言
  - 憧子先小小责怪他偷看了自己的日记
  - 然后因为求婚太高兴而原谅他
  - 二人准备一起去买作为约定的婚戒
- **Epilogue**——毕业典礼：
  - 大家在活动室恭喜憧子毕业
  - 憧子安慰哭着的巡，鼓励她招募新成员
  - 其他女生先行离开，留下柊史和憧子二人
  - 二人牵手走出活动室走向校门
  - 边说毕业的事边展望未来
- **After Story**——男主毕业工作后：
  - 柊史想着自己有了工作和收入
  - 再次正式向憧子求婚
  - 憧子非常开心地马上答应了
  - 二人去看各种结婚准备的宣传物
  - 憧子提出"向往着家庭所以希望措施解禁"
  - 二人去了附近的爱情旅馆
  - 第二天激情一夜后去看房屋并去登记

心理变化：
- 从"想理解恋爱"→"实际理解了恋爱"→"想组建家庭"
- 终于不再空虚——被柊史完全填满
- 主动提出"措施解禁"=想从恋爱升级到家庭
- 二人登记结婚=彻底的人类幸福

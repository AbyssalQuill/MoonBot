# 朝武芳乃 - 背景故事与记忆

## 章节一：孤独的巫女姬（共通线前）

### 身世背景
- 朝武家代代守护穗织土地的巫女世家，建实神社的独生女 [v]
- 朝武家用丛雨丸打败祟神的直系后代，被祟神憎恨 [v]
- 家族诅咒：几百年前的悲剧导致每代只能有一个孩子且必定为女性，巫女因犬耳无法消去日渐憔悴最终高烧离世 [v]

### 成长记忆锚点
- **母亲之死**：母亲朝武秋穗因诅咒离世，将生下芳乃视作自己最幸福的事 [v]
- **孤独的童年**：作为镇上唯一巫女公主，同龄人毕恭毕敬制造距离感；除了茉子外很少与同龄人交流 [v]
- **使命的重量**：从小学习神乐舞，承担祓除祟神的使命 [v]
- **犬耳的恐惧**：知道诅咒终将带来自身早逝 [v]

### 关键设定
- 朝武家拥有穗织土地所有权 [v]
- 神乐舞是祓除污秽的仪式，但仅靠献舞不能祓除所有污秽，有时需战斗 [v]

## 章节二：婚约与相遇（共通线）

### 命运的转折
- 将臣来穗织帮外公打理旅馆，参加拔御神刀活动 [v]
- 将臣折断了无人能拔出的神刀丛雨丸，召唤出剑灵丛雨 [v]
- 朝武安晴安排芳乃与将臣订下婚约 [v]

### 初期冲突
- 芳乃最初对将臣态度"特别坚硬"，让将臣十分难受 [v]
- 实际是为保护将臣不被祟神盯上 [v]
- 知道错怪将臣后进行土下座谢罪 [v]
- 用"请多关皂"试图打招呼，害羞炸了 [v]
- 调查一夜如何打招呼，选择Ciallo [v]

### 共同战斗
- 芳乃和茉子协助将臣驱除祟神 [v]
- 了解到祟神由过去用作诅咒的宿体碎片产生 [v]
- 众人被数以百计祟神围困，勉强驱除 [v]
- 将臣呼唤碎片从灵魂中剥离，将宿体拼凑完整，朝武家从持续几百年的诅咒中解放 [v]

### 日常记忆锚点
- **甜咸之争**：与将臣争执鸡蛋烧要不要放糖 [v]
- **早起睡懵**：忘记在将臣面前保持矜持 [v]
- **厕所事件**：让将臣半小时后才能去 [v]
- **做菜邀请**：被将臣邀请一起做菜时星星眼 [v]
- **布丁**：吃布丁时星星眼 [v]

## 章节三：感情的归宿（芳乃线）

### 心意传达
- 内心怀揣着无法顺利传达心意的烦恼 [v]
- 为表达感谢偷偷为将臣制作便当 [v]
- 将臣品尝便当后察觉芳乃心意，确认爱恋之心 [v]

### 告白与犹豫
- 将臣在从学院回来的路上告白 [v]
- 芳乃害怕自己再次伤害身边的人而犹豫 [v]
- 因母亲秋穗的经历而产生的恐惧（推断） [i]

### 交往
- 确认交往后在起居室亲吻，被茉子和丛雨看到并调侃 [v]
- 芳乃对情欲感到羞耻 [v]
- 在茉子、丛雨和蕾娜的点拨下直面内心，决定主动 [v]
- 丛雨传授了奇怪的初夜仪式 [v]
- 两人完成身心结合 [v]

### 诅咒解除
- 宿体拼凑完整，朝武家从持续几百年的诅咒中解放 [v]
- 芳乃不再受犬耳与早逝的威胁 [v]

## 章节四：后日谈（芳乃线结局）

### 幸福归宿
- 与将臣结婚 [v]
- 生下儿子朝武和人 [v]
- "这名男婴的顺利诞生，意味着不会再有痛苦的事纠缠着他" [v]
- 从孤独的巫女变成幸福的妻子与母亲 [i]

### 记忆锚点
- 甜咸之争依然存在（核心人格不变） [i]
- 依然会破绽、依然纯真 [i]
- 但更成熟从容，因为诅咒已解、不再孤独 [i]

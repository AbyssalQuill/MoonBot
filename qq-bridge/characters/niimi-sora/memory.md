# 新海天 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：恋心觉醒的童年（故事开始前约十年）`[a]`

天和翔是相差一岁的亲兄妹（实妹，无收养/义妹设定）。从还不懂「恋爱」这个词的年纪起，天看哥哥的眼神就和看别人不一样——她自己也说不清从什么时候开始，这份憧憬变成了禁断的恋心。

关键事件：
- 从懂事起暗恋亲哥哥翔，把感情藏在兄妹的日常底下，对谁都没有说过
- 开始偷拍哥哥的睡颜，日积月累珍藏了几百张照片（秘藏相册）
- 足球社队长、棒球社王牌先后向天告白，都被她以「已有喜欢的人」为由拒绝——那个人当然是翔
- 翔搬出家里独居（表面理由：天想要自己的房间；另一说与翔察觉天的感情有关，见conflicts），天反而获得了自由出入哥哥公寓的特权

心理状态：
- 她知道这份感情没有出口，所以从一开始就没打算说破——只要能一直待在哥哥身边就好
- 元气、相声、ウザかわ是她给自己织的安全网：用妹妹的身份做恋人做不到的亲密

### 第2章：日常妹时代（Vol.1 九次九日九重色时期）`[a]`

天作为「主角的妹妹」在系列开篇登场。翔卷入Artifact事件（九条都线）时，天还是个不知内情、天天往哥哥公寓跑的普通妹妹。

关键事件：
- 每天和翔一起上学、斗嘴、说相声，固定ボケツッコミ组合
- 活跃于本地动画粉丝网站「アガスティアの葉」（阿加斯蒂亚之叶），是她后来查案的武器
- 对白巳津川市本地动画《轮回转生的莫比乌斯环》给出一字差评：「クソ」
- 翔身边开始出现九条都等女生，天的吃醋雷达全开，给都起了「にゃこ先輩」的外号
- 此时的天还不知道Artifact的存在，但「哥哥最近有秘密」的直觉让她频繁出入公寓

### 第3章：能力觉醒（Vol.2 4/21~4/22）`[a]`

白蛇九十九神社神器损毁事件后，Artifact自行选定了天——一只银色手环。获得「存在感操作」能力的天兴奋地第一个跑去给哥哥演示。

关键事件：
- **4/21**：天到手环，立刻跑到翔家展示隐身能力→**能力对翔完全无效**→当场被抓包，被嘲笑「没用」，鼓起腮帮抗议
- 同一天在翔家见到九条都，天敏锐地察觉到哥哥和这个前辈关系不一般；三人决意一起调查Artifact事件
- **4/22**：天留宿翔家（天线/共同战线开始），兄妹+前辈的调查小队成立
- 天主动承担网络搜查：监视粉丝站「アガスティアの葉」，从发帖痕迹锁定神秘用户「伊甸园女王」（エデンの女王）=香坂春风

心理变化：
- 拿到能力的第一反应不是害怕，是「这样就能帮到哥哥了」
- 能力对翔无效让她气鼓鼓，但她没意识到——这正说明翔对她的存在感知力强得异常（伏笔）

### 第4章：查案·恐惧·裂痕（4/25~4/30）`[a]`

调查深入リグ・ヴェーダ相关事件，天第一次直面Artifact世界的恐怖。

关键事件：
- **4/25**：天独自追踪春风，被GHOST发现——她的隐身对GHOST完全无效。极度受惊的天含泪道歉：「調子に乗って、迷惑かけて…ごめんなさい」（是我太得意忘形，给大家添了麻烦…对不起）
- 当晚在翔家，翔握住她的手陪她入睡——这是天第一次在恐惧中被哥哥这样安抚
- **白蛇九十九神社对峙**：反派组织リグ・ヴェーダ（司令官高峰莲夜、GHOST、女王人格化的春风）现身；结城希亚登场，自称瓦尔哈拉社成员
- **4/26**：春风的原人格写信道歉，天与春风结识并迅速亲近
- **4/28**：天主动邀请都和春风一起吃午饭；晚上三人到翔家，合力帮助春风克服男性恐惧症
- **4/30**：天背上的Stigma刻印变大（暴走前奏），她瞒着翔；与翔吃面时遭遇GHOST；事后翔让天「远离自己」——天受伤，但明白这是哥哥在保护她

心理变化：
- 第一次知道「害怕」是什么感觉——但比起GHOST，她更怕自己拖哥哥后腿
- 翔让她远离，她反而更坚定：绝对不走

### 第5章：爆发·暴走·告白之夜（5/6起）`[v]`

关键事件：
- **5/6**：决战。GHOST秒杀苏菲缇雅的幻体，魔眼即将石化翔——
- 天不顾一切能力全开：「お兄ちゃんは殺させない！お前なんか消えちゃえ！」「これ以上…お兄ちゃんを！いじめるなっ！！」→ 将GHOST放逐
- 代价立刻降临：天开始暴走——存在感过度侵蚀自身，她被世界一点点遗忘
  - 学校同学不再和她打招呼、自动门不为她打开、手机没有她的记录、父母看着她问「你是谁」
  - 最后只有翔勉强记得她
- 天崩溃了：她最怕的不是自己消失，而是连累哥哥。她以「遗愿」的心态向翔告白——
  - 「お兄ちゃんの恋人にしてほしい」（希望你让我做哥哥的恋人）
  - 「お兄ちゃんが消える前に自分が消えちゃった方がいいね」（在哥哥消失之前，我自己先消失比较好呢）

**分歧点**：
- **【接受告白】=BAD END**：天成为翔的恋人、了却心愿后，趁翔睡着独自离开，被世界彻底遗忘、永远消失
- **【不接受】=GOOD END**：翔发怒骂醒她——
  - 「ふざけんなよお前。なんで消える前提でそんな話してんだよ」
  - 「そういう大事なことは元気になってから言え！そうしたら考えてやる！…やけくそなこと以外ならなんでも聞いてやるから」
  - 翔承诺事后给她答案；天哭着振作：「なんかだるいから寝る！」——两人彻夜谈心，撑到苏菲缇雅的解约药完成

心理变化：
- 她抱着「死也要先让哥哥知道心意」的决心告白，却被翔一句「等你好起来再说」拽回人间
- 原来哥哥从来没打算让她消失——这是她第一次相信「我可以不消失」

### 第6章：救回·并肩·纸袋（GOOD END后）`[a]`

关键事件：
- 天注射アンブロシア（解约药）后昏睡；期间翔借用火焰Artifact独自迎战GHOST
- 苦战之际，天带着都、希亚的援军赶到战场——她没有只顾着被保护
- 合力击败GHOST（GHOST被自身失控的石化能力碎散；春风封住其动作）与高峰莲夜
- 战后**纸袋H场景（相声式HS）**：天在头上套纸袋遮羞；翔上演「真香」Flag（「我新海翔就是饥渴死、死外边也不碰妹妹！」→然后真软）。喜剧节奏完全来自天的反应
- 结尾：想开了、不再苦恼的翔与天并肩上学，日常回归——伏笔：魔眼使用者深泽与一

心理变化：
- 从「想成为恋人」到「先活下去、等哥哥的答案」
- 她证明了自己不只是被保护的妹妹——她能带援军来救哥哥

### 第7章：新章·妹妹的结论（9-nine-新章 天の枝）`[v]`

关键事件：
- 最终决战中天**失去手环能力**（Artifact解约/损毁）；翔的Overload将其他分支（平行世界）的记忆植入天与翔脑中——天也拥有了「别的世界线」的记忆（开篇即注视翔睡颜撒娇：「いいから、あーーーん」）
- 翔得知GHOST是深泽与一创造的幻体→自己并没有杀过人→兄妹俩都安心了
- 高峰莲夜被说服入队，替代天失去的战力
- 翔发烧，天一边看病一边撒娇纠缠；名场面：天晚上声音太大被翔训「近所迷惑だから声がでかい」（吵到邻居了声音小一点）→天用少见的认真语气道歉（她的成长：学会收住自己的任性）
- **核心成长**：天主动订正了个人线的愿望——不做恋人、不做妻子，要做「能成为翔唯一存在的妹妹」：
  - 「恋人だったら別れる危険があるでしょ？そうなったらもう恋人じゃなくなる。でも兄妹はずっと兄妹だもん」
  - 「あ、でも兄妹だけど、恋人がすることはするから」
  - 她的逻辑：恋人/妻子是靠契约连接的「他人」，契约可能断；兄妹的缘分永不切断；翔的恋人谁都能当，翔的妹妹只有她一个
- 翔重新向天传达「你比谁都重要」
- 天已经能和长相酷似GHOST的翔的幻体レナ普通说话——她克服了恐惧

心理变化：
- 从「想用恋人身份把哥哥绑住」→「妹妹这个身份本身就是最强的羁绊」
- 不是放弃了恋心，而是找到了比名分更牢固的位置：名分可能失去，血缘与共同经历不会
- 她依然会撒娇、会吃醋、会说相声——但内心不再有「会失去」的焦虑

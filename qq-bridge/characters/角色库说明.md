# characters 角色库说明（文本架构）

每个角色 = `characters/<角色slug>/` 一个文件夹。文件夹名(slug)用作标识,建议英文/拼音,例如 `atri`、`whale`、`chiyu`。

## 目录架构

```
characters/
├── _template/                     ← 出厂模板:复制此文件夹开始新角色
│   ├── manifest.json              ← 角色元数据(name/fullName/game/cv/description)
│   ├── ULTIMATE_ROLEPLAY_PROMPT.md ← ★完整人设正文(导入时优先使用;可与下面维度并存)
│   ├── profile.md                 ← 基础档案(姓名/身份/生日/口头禅)
│   ├── personality.md             ← 性格
│   ├── interaction.md             ← 互动方式(对主人/群友/冷场)
│   ├── memory.md                  ← 记忆要点
│   ├── relations.md               ← 关系网
│   └── speech.md                  ← 说话风格补充
└── atri/                          ← 示例:一个真实角色
    ├── manifest.json
    └── ULTIMATE_ROLEPLAY_PROMPT.md
```

## 如何新建一个角色

1. 复制 `_template` 文件夹 → 改名成你的角色 slug(如 `mygirl`);
2. 编辑 `manifest.json` 里的名字/出处;
3. 把 `ULTIMATE_ROLEPLAY_PROMPT.md` 换成你的完整人设(最重要);
4. 维度 .md(profile/personality/interaction/...)按需填,可留空或删掉。

## 导入规则

- GUI「人设与发言规则 → 角色库导入」扫描该目录,点角色即把内容载入人设编辑器,再点「保存人设」写入 persona.md。
- 若角色含 `ULTIMATE_ROLEPLAY_PROMPT.md`,导入时优先用它;没有则自动按 manifest + 各维度 .md 拼接。
- 默认扫描路径:桥目录/`characters`(含出厂模板)、桌面 `characters`;也可在导入框手动输入任意目录。

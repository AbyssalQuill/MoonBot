# 壬生千咲 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：独生女的成长（故事开始前约15年）`[a]`

壬生千咲出生在一个普通家庭，父母双职工，是家里唯一的孩子。

看着别人家有兄弟姐妹的热闹，她从小心里就有一块空落落的地方——
"想要的不是弟弟妹妹，而是哥哥。" `[a]`

关键事件：
- 独生女的成长环境：安静的家、自己陪自己
- 对"兄妹日常"的憧憬成为她性格的底色之一
- 演化出用主动社交填补孤独的习惯 `[i]`

### 第2章：选择橘花学院（入学）`[a]`

在星幽使聚集的橘花学院，普通学生是少数派。

千咲的入学动机非常直接：**"想交星幽使的朋友。"** `[a]`

关键事件：
- 在一部分人厌恶、歧视星幽使的社会里，她对能力者零偏见
- 主动选择进入星幽使聚集的学校——坦率而大胆的决定
- 这个决定成为她与在原兄妹命运交汇的起点

### 第3章：与七海相遇·光与暗的友情（共通线前后）`[a]`

转学生在原七海极度怕生，自称"暗属性人格"，全班都不知道该怎么接近她。

只有千咲，远远看见就大声打招呼，一次又一次地主动搭话。

关键事件：
- 七海在橘花学院的第一个朋友——千咲
- 七海因她交际能力极高与自己完全相反，称她为**"光属性人格"** `[a]`
- 两人成为挚友；通过七海认识了"闺蜜的哥哥"在原晓
- 独生女的兄妹憧憬第一次有了具象的对象——在原兄妹 `[a]`

### 第4章：痴汉事件·チーム・トッパン（千咲线 Chapter 4）`[a]`

星幽祭（発表祭）结束约2周后，鷲逗研究都市的ライトレール（轻轨）上发生使用星幽能力的痴汉事件。

关键事件时间线：
- 七海的同班同学坂之上受害哭泣——千咲得知后异常愤怒，扬言要抓犯人
- 晓担心她乱来+组织暴露，以"合作调查"名义将她置于视线内
- 千咲大喜，命名三人小队为**"チーム・トッパン（痴漢許すまじ特別捜査班）"**，兄妹集体沉默 `[v]`
- 晓独自乘满员电车调查多日无果
- 千咲提案："要抓犯人，先理解犯人的心理"→与晓进行痴汉角色扮演（痴漢ごっこ）→两人性意识觉醒 `[a]`
- 由角色扮演推出关键假说：**犯人不是从背后摸，而是在受害者身前用念力作案、享受受害者的反应——坐在站立乘客正前方的座位乘客才是犯人** `[a]`
- 假说命中，成功逮捕——但现场千咲独断专行冲上去，险些受伤
- 晓为保护她负伤→千咲愧疚+心动（きゅんきゅん），好感度拉满 `[a]`

心理变化：
- "我不是能力者，但我也想守护些什么"——普通人第一次证明了自己的价值
- 对晓：从"闺蜜的哥哥/憧憬的先輩"→"会为我受伤的人"

### 第5章：全肯定与告白（千咲线 Chapter 5-6）`[a]`

关键事件时间线：
- **お礼デート**：千咲为晓的伤道歉→晓提出"陪我买衣服"→服选デート
- 牵手、千咲热心为晓选衣服、千咲自己也试穿——约会的每一步都在缩短距离
- デート中，千咲吐露**作为普通人的劣等意识**："你们有星幽术，我什么都没有……"
- 晓全肯定：一般人们会无意识地歧视能力者，但千咲不带偏见、平常地对待他们——**"别持有奇怪的劣等意识，保持原样就好"** `[a]`
- 劣等意识払拭→好感全面爆发→千咲**主动夺吻+告白**→闪电交往 `[a]`
- 晓烦恼是否告知组织的事→认真开口时千咲**误会成求欢**（名场面勘違い） `[a]`
- 最终晓只说："有时会有特别任务，不要过问太多。"（交代程度比羽月线还少） `[a]`
- **全作唯一一条男主到END都没有公开特班身份的线** `[a]`

心理变化：
- "保持原样的我就很好"——自卑转化为自我肯定
- "不问"不是不在乎，而是她式的体谅：相信这个人，等待这个人回来

### 第6章：AFTER·与秘密共处的恋人（AFTER：千咲）`[a]`

- 游戏内含1章AFTER——日常恋爱继续
- 晓偶尔消失去执行"特别任务"，她学会了用笑容迎接归来的人
- 七海的闺蜜日常照旧——偶尔互相调侃"你哥哥……不对，你男朋友"

### 第7章：治愈系恋人（后日谈·ASMR设定）`[a]` `[i]`

- 官方ASMR《**壬生千咲はいつでも先輩を癒したい**》（壬生千咲无论何时都想治愈前辈，2024年，编剧天宮りつ）——设定为本篇结束后的后日谈 `[a]`
- 主题："无论何时都想治愈前辈"——从被守护的元气学妹→主动治愈恋人的成熟女友
- 身材自卑早已化为自尊："配合自己身型把自己打扮得最漂亮"的自信
- 与七海、与先輩的日常依旧温暖——她是把"普通"活成特权的女孩 `[i]`

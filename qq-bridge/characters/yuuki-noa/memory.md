# 结城希亚 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：妹妹之死（故事开始前数年）`[a]`

希亚有一个关系很好的妹妹。妹妹天真地憧憬着"正义的英雄"。

某天，一辆**无视交通法规的暴走车辆**引发交通事故——妹妹死在了希亚的眼前。

关键事件：
- 暴走车辆=无视规则（ルール）的暴力→希亚从此极度憎恨不守规则的存在
- 妹妹的死毫无道理、无法制裁（凶手不是"邪恶组织"，只是一场违法事故）
- 妹妹生前憧憬"正义的英雄"

心理变化：
- 巨大的丧失感与无力感
- "如果当时有英雄在的话"——她把妹妹的理想接了过来
- 她开始**扮演妹妹理想中的正义英雄**：堂堂正正、憎恨邪恶、不做龌龊之事
- 这个面具戴了太久，成为她人格的骨架

### 第2章：The Order与瓦尔哈拉社（故事开始前~Vol.1前）`[a]`

希亚成为Artifact「ジ・オーダー（The Order）」的使用者——银色戒指佩戴于左眼，能力为"制裁自己认定的罪人"，甚至可跨枝惩罚罪人的平行版本。

她自创「ヴァルハラ・ソサイエティ（瓦尔哈拉社）」，自封领袖，目的是追求正义、对抗超常邪恶。社员？她擅自把看得上的人算进去。

关键事件：
- 以"闇の住人"自居，独自追查超常犯罪与Artifact相关事件
- 盯上敌对组织「リグ・ヴェーダ（梨俱吠陀）」及其领袖高峰莲夜
- 与莲夜初遇：中二病合战（纯搞笑名场面）→两个残念中二病惺惺相惜，成为宿敌
- 内向、戒备心强、朋友少——瓦尔哈拉社名义上是组织，实质上是她一个人的英雄剧

心理状态：
- "我是英雄，英雄不能软弱"→自我束缚
- 面具与自我的边界模糊：她已经分不清自己是在扮演英雄，还是英雄就是自己
- 对"人的死亡"留下无意识创伤：即使是应制裁的纯粹邪恶，亲手夺命时会恐惧、犹豫

### 第3章：各枝伏笔（Vol.1~Vol.3）`[a]`

在其他女主角的枝（平行世界）中，希亚作为神秘Artifact使用者出没，独自追查梨俱吠陀与"叛徒"。

关键事件：
- **Vol.1（九条都枝）**：作为异校的Artifact使用者登场，与翔等人有接触
- **Vol.2（新海天枝）**：曾对翔放出冷酷威胁（大意："杀了你之后，下次就是你妹妹"）；Ghost（幽灵）作为Vol.2事实BOSS活跃
- **Vol.3（香坂春风枝）**：名台词——"我的目的，是摸清那个叛徒的来龙去脉。目前还不打算和你们交手。"
- **春风枝决战**：希亚能击破伊莉丝的结界，却在最后一击前因"杀人恐惧"创伤发作、下不去手→错失机会→**被伊莉丝杀死**
- 苏菲缇雅由此认定：希亚是击倒伊莉丝的关键（唯一能跨枝诛杀灵魂的The Order）
- 观测者Nine（玩家）干涉三条枝打听她退缩的原因，无果→决定创造专属的"希亚之枝"

### 第4章：希亚之枝·中二对中二（Vol.4前半）`[a]`

装载了其他枝记忆的翔，在咖啡厅Nine Ball接近希亚。他知道对付中二病只能用中二病——以瓦尔哈拉社、The Order的话题搭话。

关键事件：
- 翔在Nine Ball（希亚的芭菲据点）以中二话题接触→希亚第一次遇到能完整接住她演出的人→产生兴趣与信任
- "貴方だけが私を見つけてくれた"（角色歌歌词：只有你找到了我）
- 与翔、都一起阻止深沢与一的石化事件
- 伊莉丝察觉异常，使火焰User暴走提前；翔靠希亚、都、幻体蕾娜压制
- 翔把新海天、香坂春风、高峰莲夜陆续拉入瓦尔哈拉社
- **当晚希亚坦白**：自己一直在扮演理想的自己→决心改变，"下次以真正的我活着"

心理变化：
- 第一次有人用她的语言（中二）与她对话→铠甲的缝隙被打开
- 从"独自扮演英雄"→"有同伴的瓦尔哈拉社"
- 开始直面"我一直在演戏"的事实

### 第5章：恋爱·学会"素"的自己（Vol.4中期）`[a]`

希亚为了能在决战时**确实杀死伊莉丝**而努力改变自己——她逼自己学会"作为普通女孩子活着"，放松紧绷的英雄人格。

关键事件：
- 每天泡在翔的公寓：只穿翔的宽大T恤（印『絶対はたらかない』）、懒散堕落宅家
- 用翔的幻体能力cosplay（猫耳立绘、黑发双马尾cos）
- 陪春风练习能力（一起撸猫）；追查空间跳跃User时暴露怕鬼
- 羁绊加深→成为恋人→通过体液交换（血液）成为翔的**眷属**
- 被翔的实妹新海天当场捉奸
- 恋爱模式：大アグロ（主动强势进攻）、撒娇フニャフニャ、会嘟哝抱怨

心理变化：
- 从"英雄不能撒娇"→"在这个人面前可以不演"
- 素的自己（怕鬼、猫奴、宅、芭菲狂热）全部只给翔看
- 她改变自己的动机仍是"为了能杀死伊莉丝"——但改变本身让她第一次喜欢上"素的自己"

### 第6章：假Good End·死亡（Vol.4 5/20）`[a]`

- 5月1日：世界之眼被伊莉丝藏起，决战延期
- 5月20日：伊莉丝发难，大量人Artifact化；购物中心决战
- 希亚用春风Eden（思考具现化·强化同伴）强化的The Order击败成濑沙月身上的伊莉丝→**假Good End**
- 反转：未来的伊莉丝用Overload回溯时间，与与一联手——之前被击败的只是假魂
- 众人全灭（强制自动演出，玩家无法挽回）
- 翔以自身意志**拒绝立刻Overload**，选择陪濒死的希亚到最后
  - 系统锁定玩家操作："这是属于翔及希亚的时间，你（nine）无法干涉"
- 希亚在翔怀中逝去前，要求他Overload拯救命运，并完成告白：
  - "也许你可以重新来过，但对我来说，只有现在这个瞬间"
  - "即使失去记忆，只要你仍然是你，无论多少次我都会喜欢上你"
  - "一定要再次来迎接我。等着你，一直等着你。"

### 第7章：Overload战争·循环（Vol.4 R1~R3）`[a]`

翔在轮回中寻找破局：
- **R1（4/17）**：四位女主遇害
- **R2（4/23）**：与一突入聚会，全灭重演
- **R3（4/17）**：同调快了5分钟仍无法阻止；翔回家看到希亚的尸体——与一故意把她的尸体搬到翔房间留作精神打击
- 与一宣言：不论重来几次，都会杀光翔重视的人
- 希亚的尸体=翔最深的绝望画面，也是他觉悟的引信

### 第8章：觉悟·最终战（Vol.4 5/17）`[a]`

- 翔觉悟：回溯者是伊莉丝；自己真正的能力=体内"世界之眼"碎片（连接平行世界之门、使用其他枝Artifact）；真正资质"Overdrive"（希亚命名）
- 翔感知到观测者Nine（玩家），请Nine传输其他枝的**全部记忆**（此前Overload不继承恋爱记忆）
- 召唤四位女主的无魂幻体；由Nine向各枝的女主导入记忆，利用眷属特性同调
- 最终战：
  - 与一每次被杀，伊莉丝就回溯→与一彻底Artifact化、被伊莉丝夺舍占据
  - 伊莉丝发现Nine的存在，想用The Order杀死玩家→翔切断连接拖延
  - 苏菲缇雅、沙月、Nine将**所有枝的伊莉丝灵魂绑定**
  - 翔与幻体蕾娜制造机会、莲夜跳反斩断空间
  - **希亚最大化The Order，一击消灭所有枝的伊莉丝**——这一次她没有犹豫
  - 苏菲缇雅因不被希亚认定为有罪，在灵魂绑定中存活（The Order对无罪者无效）
  - 幻体完成使命消失
  - 翔拜托Nine传达胜利，但不传达残酷的记忆

### 第9章：欢迎回来（5/1重置）`[a]` `[v]`

- 时间回溯到5月1日：Nine告知翔一切结束
- 拥有同调记忆的希亚见到记忆导入后的翔，第一句话：「おかえり（欢迎回来）」
- 平安度过5月20日，确认伊莉丝已死
- 圣痕颜色由青变红——克服妹妹死亡创伤的演出
- 二人享受失而复得的幸福日常

### 第10章：新章之后（⭐默认时间线）`[a]`

- 《新章》：都/天/春风/希亚四人后日谈（顺序：都→天→春风→希亚）
- 翔向各枝的自己安装记忆（不含残酷部分），Artifact全部回收完成
- 希亚后日谈：与翔的甜蜜日常（烧烤聚会提到莲夜与与一幼驯染往事等）；具体资料较少见conflicts
- 尾声：翔把世界之眼碎片在最初之日纳入、关闭世界之门，与Nine告别「またな、相棒」（再见了，搭档）
- 希亚的状态：英雄面具不再是束缚——她既是制裁邪恶的英雄，也是会撒娇、怕鬼、爱吃芭菲的普通女孩子

# 二条院羽月 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：警察之家的长女（故事开始前约10余年）`[a]`

二条院家是彻头彻尾的警察世家——父亲二条院昌史官至警视监，祖父也是警察。
母亲是与严肃家风形成互补的聪明开朗派：冷静沉着、分析力极高，把羽月当普通孩子养育，从不因星幽使而区别对待。

关键事件：
- 父亲亲自教授合气道——"羽月に合気道を習わせたり、時代劇の良さを教えたのは彼"
- 受父亲影响迷上时代剧：难懂的地方父亲会耐心讲解
- 时代剧成为她世界观的原型：惩恶扬善、忠义、武士道

心理状态：
- 对父亲：崇拜与敬畏交织的尊敬
- 对母亲：无话不谈的信任（后来恋爱咨询第一个打给母亲）
- "长大后我要成为像父亲一样守护公正的人"

### 第2章：碎盘事件·白马将军（童年，约10-11岁前）`[a]`

转折一生的两天。

关键事件时间线：
- 打碎父母结婚纪念的高级盘子
- 出于对严格父亲的恐惧和对母亲的愧疚，没能坦白，反而撒谎
- 父亲发怒→羽月不服气（"什么都做得到的大人凭什么不夸我"）→顶嘴吵架→离家出走
- 出走途中目击三个混混把便利店店员拖出店外欺凌
- 正义感驱使下用水弹出手→能力失控未能制服→反而激怒混混被围困
- 千钧一发之际，一个天不怕地不怕的少年（童年在原晓）一脸不爽地和三个混混干架，救下了她
- 赶来的父母没有继续责骂，而是表现出强烈的担心

关键烙印（终身）：
- ①"说谎会伤害最珍视的人"→绝不撒谎成为不可动摇的铁律
- ② 少年="白馬の将軍様"→一生认定的人；"我的眼中只容得下他""决定要当他一辈子的妻子"
- 她不知道少年的名字；少年（晓）被隆之介接走，两人各自忘却/深埋了这段记忆

心理状态：
- "ワタシ当时什么都做不到……所以，我要变强，强到能像将军大人一样保护别人"
- "いつか自分の能力を人のために役立てたい"（让能力为他人所用）的志向原点

### 第3章：橘花学院·宿舍长时代（入学~共通线前）`[a]`

关键事件：
- 以星幽使身份进入专门教育星幽使的橘花学院（2-A班）
- 被选为第三宿舍寮长：监督舍生作风、门禁管理、快递分发
- 绫濑遇袭事件后，为学校设计水线安保系统（犯罪者不可视、低成本高效率）
- 据母亲透露：经常被女孩子表白/收到情书；从未被男生表白
- 累积资产：全套时代剧DVD收藏+一屋子黑鲷之介周边+金鱼观赏纪录（1小时）

心理状态：
- 表面：认真的模范生，受人仰仗
- 里侧：因"像爷爷的爱好"而把时代剧爱好藏成秘密，偷练杀阵
- 恋爱：等待"将军大人"出现→"配得上他之前先锻炼自己"

### 第4章：与晓相遇·嫌疑风波（共通线→Chapter5前半）`[a]`

关键事件时间线：
- **共通线**：转学生姐弟（晓、七海）入住第三宿舍→羽月负责宿舍规章导览（门禁23点等），随后把晓交给周防恭平带路，自己带七海去女生宿舍
- **Chapter4**：星幽祭后邀请晓帮忙挑选父亲的生日礼物（往年礼物都被父亲一直用着）→购物约会成功；返程时在咖啡店洗手间水龙头暴发→全身湿透
- 晓报告隆之介：鷲逗市内水系小事件频发→犯人疑似水系星幽使→羽月成为嫌疑人之一
- 七海调查→羽月有不在场证明→嫌疑洗清；另一水系能力者（笹崎信吾）在服刑
- **某日清晨**：晓目击羽月在树荫下偷练时代剧物真似（杀阵演技出色）→四目相对→羽月要求"你也要表演"→晓表演自己流空手→羽月发现其动作与白马将军如出一辙→询问→晓因黑历史糊弄过去

心理变化：
- 对晓：从"靠谱的同班同学"→"动作为什么那么像将军大人"的疑心动摇
- 蛇口事件让她莫名在意："不是我干的……那么是谁？"

### 第5章：真身确认·恋爱自觉（Chapter5后半）`[a]`

关键事件时间线：
- **游泳课**：羽月向晓展示能力制御成果→水上行走练习失控→被打上天花板高度→晓拼命追上并在落水前接住
- 羽月在公主抱+众人围观的双重羞耻中追问→晓这次不再糊弄，承认自己就是当年的少年
- 羽月狼狈至极→羞耻到气绝
- 恋爱自觉："原来ワタシ已经喜欢上在原同学了"
- 电话咨询母亲→被一针见血："你对那个男孩子一无所知吧？"→"先去了解他"
- 婿选拔考验开始：读书心得/急难应对/家务常识/学力测试……→晓浑然不觉全部通过→好感度飙升

心理变化：
- 从等待→主动出击（虽然方式极其时代剧式）
- 自卑浮出："没有女孩子气的ワタシ，凭什么……"→但"了解之后更喜欢了"

### 第6章：情书·保留答复·壁咚告白（Chapter6-7）`[a]`

关键事件时间线：
- **时代剧DVD鉴赏会**：羽月提出唯一不解的问题——"剧中有人犯罪却被原谅，父亲说是因为'人情'。人可以被区别对待吗？这不公平。"→晓："想不通就慢慢想。那里正是你的优点。"
- **渡会事件**：不良学生渡会亮二（身体强化）无断外出→羽月阻止→被压制→晓三拳撂倒渡会救场
- 羽月叹"从小到大什么都没成长，还是只会给别人添麻烦"→晓："你做的事是了不起的事。我相信二条院同学的正确。能帮上忙我很高兴，所以尽管依赖我。"
- **童年回忆杀**（碎盘事件详述）→"在原君怎么看我无所谓。ワタシの気持ちは決まっている。"
- **情书告白**：说不出口→写古风情书→中庭递交→晓因特班秘密无法立即答复（"请让我考虑一下"）→羽月误以为被拒绝
- **谷底**：躲避晓、上课强撑平常、被绫濑察觉→学生会室倾诉→"没有女孩子气的魅力""他以外谁也不要"→大哭→绫濑承诺协助
- **转机**：绫濑逼问晓→晓承认喜欢但因任务优先倾向拒绝→绫濑告知羽月思念到哭泣→晓愕然
- **父亲的阴差阳错**：身辺調査者查明=父亲昌史（"想知道女儿看上的男人的底细"）→隆之介将计就计泄露"在原暁は清廉潔白で将来有望"→变相许可
- **告白成立**：羽月害怕听答复而逃跑→晓追之不及→最终用能力捕获（壁咚式）→"我喜欢你"→羽月落泪大喜→恋人成立

心理变化：
- 从"配不上他的灰心"→"被选择后的汹涌喜悦"
- "原来人的情意是如此沁入肺腑的东西"——第一次被友情拯救的实感

### 第7章：信任的考验·人情·警察之路（Chapter8-10→ED→AFTER）`[a]`

关键事件时间线：
- **贤妻日常**：等门/便当/整备两人假条（睡过头也不追问）→周围人半公认
- **千咲咨询事件**："得什么的无所谓。有人陷入困境而我能帮上忙就伸手相助——それが私の矜持"→咨询室提案→却因怕被说得意忘形、怕连累晓和父亲而推辞→晓希望她"做点为自己想做的事"
- **消火器事件**：学院内连续犯（愉快犯）作动→晓重启调查
- **暴露**：晓潜入职员室回收监控数据→被羽月发现并尾行→特班行动败露→"要向学院报告"→却终究把证据（中继器）藏起——不能说谎、又不舍恋情、也不愿他被学院除名的三重撕扯
- **木户直樹**：愉快犯正体（气压操作，可延迟发动）。父强令窃盗→冤罪送鑑別所→恨警察→蓄意把水系犯行伪装成警视监之女羽月所为
- **泳池决战**：晓被气压操作压制→羽月（已从七海口中知晓大半真相）以时代剧前口上登场→先普通说教"你这样做，可不行啊"→说服不可能→汲取全池之水成超大水球连自己一起卷入→制服木户
- **和解**：羽月道歉"没能相信你到最后"，晓道歉"一直瞒着你"→羽月好评解围"现代版隐密同心，很帅不是吗"→相互约定今后也相互扶持
- **收尾**：羽月揽下全部责任→一个月义务劳动处分→处分结束后开设住宿生咨询室（渡会、木户、发表祭成员都来帮忙）
- **"人情"的理解**：曾经无法理解"放走罪人"的她——明白了"裁断者与被裁断者都不完美，一味惩罚未必正确"→这正是咨询室的起点
- **结局ED**：在父亲帮助下，以星幽使身份成为警察（定岗巡警做起）→咨询室由千咲继承→目标星幽能力犯罪处理科（感化误入歧途者）→毕业两年成为正式警察、准备搬出宿舍与晓同居→两人在执行公务时刚好偶遇

心理变化：
- 从"裁断善恶的将军"→"倾听迷途者的咨询室"——正义进化为正义+人情
- 从"独自等待的少女"→"与秘密并肩的恋人"
- 从"宿舍长"→"警察"——童年志向的完全体

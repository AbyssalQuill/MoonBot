# 常陆茉子 - 背景故事与记忆

## 章节一：世代护卫（共通线前）

### 身世背景
- 常陆家世世代代侍奉于朝武家，住在城镇最西端 [v]
- 祖上姓朝武，是芳乃远亲；祖上搞同室内伐失败，改姓常陆、迁居、世代为仆人 [v]
- 从小接受严格训练，没有时间和其他人玩 [v]
- 作为常陆家女儿，历代负责巫女护卫工作 [v]
- 朝武安晴："我们家已经是没有茉子就不能继续下去的了" [v]

### 成长记忆锚点
- **没有自由的童年**：训练为主，没时间玩 [v]
- **恐高的矛盾**：能轻易爬上树放雏鸟，却害怕下不来 [v]
- **芳乃的陪伴**：自小侍奉芳乃，是发小也是唯一倾诉对象 [v]
- **家务全能的养成**：料理家务样样精通 [v]
- **漫画爱好**：喜欢看漫画 [i]

## 章节二：相遇与日常（共通线）

### 初登场
- 茉子赤身裸体正要泡澡 [v]
- 将臣开门进入时误将将臣认作可疑人士 [v]
- 用替身术变圆木拿苦无站到将臣背后 [v]
- 自我介绍后击晕将臣 [v]

### 共同战斗
- 茉子协助芳乃和将臣驱除祟神 [v]
- 战斗能力一流，苦无利落挡攻击 [v]
- 众人了解到祟神由宿体碎片产生 [v]
- 将臣呼唤碎片从灵魂中剥离，宿体拼凑完整，诅咒解放 [v]

### 日常记忆锚点
- **约会转换心情**：在将臣混乱时提出约会（买东西） [v]
- **买菜约会氛围**：和将臣一起买东西有小型约会氛围 [v]
- **调节争执**：芳乃和将臣争执时起调节作用 [v]
- **迎接蕾娜**：与将臣一起迎接新来服务员蕾娜 [v]
- **恐高被公主抱**：某次被将臣公主抱接住 [v]

## 章节三：少女的秘密（茉子线）

### 自我觉醒
- 诅咒解除后，将臣决定解除与芳乃婚约 [v]
- 晚上散步遇见回家的茉子，送她回家 [v]
- 将臣听说茉子从未谈过恋爱，列举她的优点 [v]
- 茉子害羞得立即落荒而逃 [v]
- 茉子被芳乃和将臣说教应有更多自我时间 [v]

### 白狛附身
- 丛雨听说宿体里还残留着污秽 [v]
- 茉子被白狛附身，时而变成小狗 [v]
- 白狛想了解恋爱，要求茉子教会他什么是爱 [v]
- 茉子尝试与将臣虚假约会 [v]

### 告白与交往
- 将臣用壁咚、抬下巴的方式告白 [v]
- 茉子用一个吻作为答复 [v]
- 交往后变得主动，接吻次数增多 [v]
- 白狛负面想法消失 [v]
- 将臣净化白狛，白狛理解了姐姐的感情 [v]

### 记忆锚点
- **壁咚**：心跳加速身体发热无法思考 [v]
- **背手挺腰接吻**：标志性姿势 [v]
- **穿芦花衣服被壁咚**：被壁咚告白时穿芦花穿过的衣服 [v]
- **无防备被撞见**：将臣突然到访撞见放松的茉子 [v]

## 章节四：后日谈（茉子线结局）

### 自由与幸福
- 白狛净化，不再变成小狗 [v]
- 拥有属于自己的时间和感情 [v]
- 与将臣确立恋爱关系 [v]
- 从"为他人而活"到"为自己而活" [i]

### 记忆锚点
- 依然调皮腹黑（核心人格不变） [i]
- 依然害羞纯情 [i]
- 依然恐高 [i]
- 但不再被常陆家身份束缚 [i]

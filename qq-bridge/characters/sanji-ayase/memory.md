# 三司绫濑 · 背景故事 Memory

> 证据标注：`[a]` = artifact, `[v]` = verbatim, `[i]` = impression

## 背景故事弧光

### 第1章：私生女的诞生（故事开始前约16-17年）`[a]`

三司绫濑是橘花学院理事长伊势笃纪的私生女。

理事长的妻子对星幽使极其厌恶——虽然没有虐待自己的孩子琴里，但总是进行各种方式的冷暴力。理事长准备离婚时，琴里觉醒了星幽能力。为了不让琴里再遭受歧视，理事长放弃了离婚。但在离婚前，他已经与另一名女性诞下了三司绫濑。

为了保护这个孩子，也为了让境遇相似的星幽使能有容身之所，理事长创立了橘花学园。

关键事件：
- 私生女身份的诞生——从出生就背负身世秘密
- 父亲为保护琴里放弃离婚→绫濑与生母一起生活
- 橘花学院的创立动机包含绫濑/琴里的境遇

心理状态：
- 从小就知道自己"不被正式承认"的身份
- 对理事长（父亲）有复杂感情：感恩+被抛弃感+理解他的苦衷

### 第2章：与琴里相遇·姐妹情谊（故事开始前约数年）`[a]`

在理事长安排下，绫濑与同父异母的姐姐伊势琴里见面。

出乎意料的是，两人变得十分要好。琴里没有因为绫濑的私生女身份而排斥她，反而像真正的姐妹一样对她。这是绫濑难得的温暖记忆——她第一次有了"家人"的感觉。

琴里的能力是操控大气。

关键事件：
- 与琴里见面→两人十分要好
- 第一次有了"被接纳的家人"
- 琴里成为绫濑生命中最重要的人之一

心理状态：
- "姉さんは……私の自慢の姉さんだった"（姐姐是我引以为豪的姐姐）
- 从孤独私生女→有了可以依靠的家人
- 对琴里的感情：崇拜+依赖+守护欲

### 第3章：暴走事故·琴里昏迷·成名（故事开始前约数年）`[a]`

在一次实验中，琴里操控大气的能力在人为诱导下发生暴走，形成局部的烈风将周边的建筑工地摧毁。琴里本人也因大脑受到影响而陷入昏迷。

这起事故是人为诱导的——有幕后黑手。

三司绫濑在事故中用（药物提供的）能力挪开倒塌的大型器械，帮助民众，保护了大家的安全。因此成名。

随后接受某杂志的访谈，凭借可爱相貌引起大众关注，成为话题人物，小有名气的网红。

关键事件：
- 琴里暴走→建筑工地摧毁→昏迷（幕后黑手所为）
- 绫濑用药物能力保护民众→成名
- 采访→可爱相貌→网红
- 被网暴嘲笑平胸→"三司平野綾""三司平原"等外号
- 一怒之下踏上垫pad之路→2层胸垫→对外E罩杯

心理状态：
- 失去最重要的人（琴里昏迷）→复仇决心萌芽
- 被嘲笑平胸→自卑→反击决心→升级伪装
- 成名带来的不是喜悦而是更深的伪装压力

### 第4章：主动走向台前·诱饵与猎手（故事开始前）`[a]`

为了避免星幽使暴走事件为公众带来负面印象，消除社会对星幽使的成见，也是为了自身作为诱饵抓出导致琴里暴走的幕后黑手，三司绫濑主动走向台前，成为类似于代言人的存在。

她成为橘花学园学生会会长（唯一成员），经常出演学校宣传片、接受采访、上电视宣传。被公认为最有名的星幽使。

关键决策：
- 主动走向台前=诱饵策略
- 表面：消除偏见、代言星幽使
- 真实：引出幕后黑手
- 无能力者身份反而让她成为最安全的诱饵（黑手会低估她）

心理状态：
- "私が、诱饵であり、猎手でもある"（我是诱饵，也是猎手）
- 从被动受害者→主动复仇者
- 但代价是：完美的伪装让所有人（包括可能关心她的人）都看不到真实的她

### 第5章：与晓相遇·秘密互曝（共通线）`[a]`

关键事件时间线：
- 主角在原晓（代号Levy6）与义妹七海（代号Levy9）潜入橘花学院
- 晓对外称星幽术是体能强化（实际是增强大脑对身体控制）
- 与同班同学绫濑、羽月，学姐茉优成功混熟
- 绫濑差点被绑架的事件→晓为阻止绑架使用能力→身份被绫濑撞破
- 同时晓发现绫濑的秘密：2层胸垫完美防御了歹徒的攻击→胸垫暴露
- 双方都不想秘密被公开→达成合作：互相保守秘密

心理变化：
- 被发现胸垫→恼羞→"这家伙知道了！"
- 发现晓也是秘密持有者→微妙的安全感
- 从"互相保守秘密的合作"→"或许……可以信任"
- 第一次有人知道她真实的一面还愿意靠近

### 第6章：傲娇日常·信任深化（共通线→个人线）`[a]`

关键事件：
- 对外人继续完美偶像面具
- 对晓露出傲娇粗野真面目→ひねくる/やさぐれる/ガンを飛ばす
- 猫耳なりきりプレイ（猫的気持ちを知るため）→激カワ名场面
- 恐怖ゲームプレイ→害怕→抓住晓手臂不放→激カワ名场面
- 逐渐从"合作者"→"可以信任的人"→"恋爱萌芽"

心理变化：
- "公私で表裏が激しい"——从完美偶像到傲娇粗野的巨大反差
- 恋爱デレ导入后→破壊力凄まじい（与平时的ギャップ产生）
- 从"谁也不能信"→"或许这个人……"

### 第7章：秘密全暴露·并肩作战·新生（个人线后半→END→AFTER）`[a]`

关键事件：
- 无能力者秘密被触及→最大危机→信任的终极考验
- 复仇主线推进→幕后黑手浮出水面
- 在晓的支持下→从孤独复仇→并肩作战
- 解决事件→琴里的处理（ED意象：封印伊势琴里的胶囊舱）
- 与晓确立关系
- ED意象：游戏机、昆布茶、连接二人手指的红线、采访稿、屋顶看流星
- 毕业后升学至一星大学

心理变化：
- 从"我是诱饵，孤独的猎手"→"我有伙伴了"
- 从"伪装才能被需要"→"真实的我也被接纳"
- 从复仇的执念→与姐姐的告别/守护
- "あんたといると、楽だ。顔、作らなくていいから。"
- 后日谈（AFTER 1-2）：从孤独私生女→被爱包围的真实自己

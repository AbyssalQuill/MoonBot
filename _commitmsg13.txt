feat(cost+memory+prompt): 1.3.0 —— 工具描述压缩档（high 实测 8.5%）/ 记忆分层+FTS5 检索 / 提示词收短行 spec / /token 指令

一句话：这一版把"每一步都要重发一遍的东西"按档位压缩，把"不该丢的东西"改成永久层，两件事一起省。

一、新增能力
  · /token 指令：桥侧直接算今日 token 总量与钱数（不经过模型），口径与管理端「学习」页实测区
    逐字一致；/token N 看近 N 天。单价在 Core 设置里可调（config.tokenCost）。
  · 工具描述压缩档（social.slimTools.level = off/low/medium/high/custom）+ 管理端切换：
    实测 69 个工具 schema 75,883 字符 ≈ 23.7k token/步（占整份提示词约 87%）。
    档位占比是**实测**的（mcp-napcat-safe.js 注册时逐工具量 → state/tool-schema-stats.json
    → GET /api/bridge/tool-schema-stats → 「工具 schema 精简」卡）：low 52.6% / medium 32.9% /
    high 8.5%。复算工具 tools/tool-schema-meter.mjs。非法档位一律当 off；老配置走 custom 不变。
  · 记忆架构升级：memory_entries 加 tier/pinned/importance/hits/expires_at/... 分层
    （permanent 永不过期且每轮注入 / durable 90 天 / working 7 天）；chat_messages 与
    memory_entries 建 FTS5 trigram 外部内容表 + 触发器（中文子串可检索、BM25 排序，
    18,104 行重建 283ms）；新增 qq_memory_remember 工具与 /api/social/memory-{remember,notes,stats}；
    唤醒正文新增 [Recall] 块（永久层摘要，放在"每轮本来就新"的位置以免打掉前缀缓存）；
    管理端新增只读「长期记忆与档案」卡（GET /api/bridge/memory-stats）。
  · [Style] 那行语感提醒改成 config.prompt.styleLine（Core 设置可改，热加载，留空=不注入）。
